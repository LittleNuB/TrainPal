# 进入编辑的方案自动存入本机方案库

状态：已接受，2026-09-08，依据用户确认“所有进入方案编辑的方案自动留存”。

替代 ADR 0004、CONTEXT 中“只保留一份未存档草稿，主动另存为才进入方案库”的要求。当前编辑器仍只有一份活动方案，但每份非空、已被用户带入编辑器的方案都拥有稳定的方案库身份；后续编辑更新同一个方案，用户显式复制才产生副本。尚未接受的分析提案、失败分析和空编辑器不创建存档。快速体验方案在用户主动选用后同样存档，保持样例标识。

旧版本尚未归档的非空当前草稿，在加载时通过单一本地事务补存档；不丢动作、参数、来源和确认状态，不重新调用分析。归档与当前编辑器的保存须原子提交，失败显示可重试状态，不能显示已存档。命名缺失时提供可修改的来源/动作默认名称。

切换或新建方案之前先保存当前修改。删除方案需明确确认；删除当前编辑的方案也关闭该编辑器，保留训练记录及正在进行的训练快照。旧页面对已经删除的方案再保存应失败，不得自动复活。复制独立、修改原方案不改历史训练记录。

仍仅当前浏览器本机保存，不承诺云端备份、跨设备同步或逐次修改的历史版本。独立动作收藏/动作库不属于这一批；此前跨分块字幕参数审查问题另行处理。

2026-09-12 集成说明：方案库同时保留当前方案 revision 和已应用调整的基础值。切换方案后仍可恢复基础值；复制保留可恢复的已应用调整，但丢弃绑定原方案身份的未应用提案。没有这类元数据的旧方案仍正常打开，不补造历史基础值。
