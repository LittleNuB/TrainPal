# 视觉次数用途的平铺输出试点

2026-10-04，关联 #6/#37，承接默认关闭的次数用途合同及
`docs/design/trainpal-flat-purpose-wire-probe-20261004.md`。用户授权当前 Goal 的
必要隔离修复；本决定不切换正式 Provider、不启用新默认、不改变训练流程。

## 问题与已有证据

嵌套次数用途字段曾导致真实输出类型错误。私有平铺实验在局部交替复测及一次
完整 208 秒分析中通过格式校验，但相同输入仍出现名称/参数漏读，拉伸待确认。
这支持把可重复测试的 wire 适配整理进源码，不支持宣称语义质量或稳定性达标。

## 决定

- 仅显式构造 `ArkResponsesClient(visual_parameter_context=True,
  visual_parameter_context_format="flat")` 使用平铺表达。原格式默认为 `nested`，
  用途试点总开关仍默认 False；不加环境变量、API 参数或工厂配置。
- 与嵌套格式携带相同信息：用途、完整必要字幕短句、开始时间、结束时间。四项
  同层且全部 null 或全部非 null；合法输出确定映射回原内部模型，再执行原
  参数投影、时间、编号、动作、提醒与来源保护。不接受数组解包或字段补写。
- 验证实际发送的 JSON Schema 后才映射，拒绝缺字段、额外字段、类型转换等。
  供应商响应还须完成、无拒绝/错误/未完成详情、store=false 且回显格式一致；
  缺少这些元数据也拒绝。拒绝只影响显式平铺试点，旧路径不加这些新条件。
- 使用固定版本 jsonschema 校验器，不自制不完整的 JSON Schema 校验。字幕、
  原响应和诊断异常中的内容保持瞬态，不新增日志或持久化字段。
- 保留真实训练次数范围与组数/时长/休息；选重量条件不能变成次数目标。
  提示表达只改字段表示，原语义要求和调用方后缀保留。视频使用片段本地时间，
  contact sheet 沿用绝对时间，不引入新的时间换算。

## 验收与限制

沿用用户确认的 Provider HTTP → 候选融合公共边界，先红后绿迁移；合成测试
验证合法参数/来源保留、非法输出拒绝、旧默认和嵌套路径不变。运行完整工程检查、
E2E 与 API 一致性检查，进行 Standards/Spec 双轴审查。

真实验收必须在迁移后的同代码、同配置重复运行 68/208，并保留 39 的四动作反例、
提醒归属/来源完整性、参数及缺覆盖检查。旧私有适配器结果不能直接算作迁移后
验证。出现格式失败独立记录；合法输出仍可能识别错误，不能以 schema 通过
替代语义核验，也不能以缩短参考范围或清空提醒过关。默认启用仍需完整 Goal
门槛，而不是本 ADR 或专项测试通过。
