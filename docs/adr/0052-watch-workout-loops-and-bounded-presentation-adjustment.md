# 对着视频练采用循环参考、组间自动衔接与有界呈现调整

状态：已接受（2026-09-18，用户确认并授权自主实施）。

采用 docs/design/trainpal-watch-workout-v1-20260918.md。取代 ADR-0017 中仅播一次的呈现约束：当前选段在执行时循环，播放结束不完成训练组，完整教学范围为默认。次数由用户确认，时长由确定性计时器结束。

同动作组间休息结束后前台自动进行三秒准备倒数；第一组或新动作必须先点击“准备好了”。后台、恢复、AI 请求和故障不会自动训练。倒数不计训练时间；普通暂停恢复保留未完成组进度。

TrainPal 可接受单次语音或文字片段请求，先暂停、再通过现有 Provider 选择已知证据范围，用户预览后明确接受并继续。不得改训练量、生成时间点、修改原始出处；新选段与完整来源范围分开保存，临时回退不保存。无支持或失败使用文字入口，不提供常开监听。

视频明确要点带时间和证据类型随方案保存，训练一次显示一条，最多三条，不启用新的知识补全。ADR-0020 的 web/model 标签规则保留，但本批不实施新的 web/model 生成。

补充 ADR-0053/0051：模型判定为同次示范且时间、编号保护通过后，参数冲突不再拆成多个动作，而在一个待确认动作上保留字段冲突。不同编号/真实再次执行仍不能合并；无法确认身份则继续保留分项。

2026-09-19 分批发布：D 只启用低操作训练与已保存范围循环；E 的文字/语音入口及服务端接口另一个 Draft PR 交付。A/B 保护与本轮真实验收门槛以 trainpal-release-acceptance-20260919.md 为准。
