# 视觉上下文保真传递，不改变教学合并边界

2026-10-06，#6/#37，修复基线`e59dfe9`。沿用当前goal的本地隔离修复授权，
仅落实ADR0070的原始上下文传递，不把尚未确认的“同一教学单元”合并规则写进代码。

## 决定

- `SemanticCandidateFusion(include_visual_context=True)`显式开启；默认False。
  不接工厂、设置、公开API或演示入口，不增加模型节点、调用、重试或持久化。
- 整理结果中的非训练观察、未归属字幕判断及点字幕单独作为
  `visual_source_context`传给现有同一次分组请求。原字幕及时间完整保留，
  上游用途/归属假设仍是假设；它们不塞入某个动作的caption_context。
  普通分组和完整语音上下文分组都适用，原语音上下文不被替换。
- 上下文只能复核已有成员和已有提醒。非训练观察、未归属字幕、点字幕均不是
  训练成员、参数来源、提醒或独立确认票，不能生成新的tip ID或自动搬运。
  点字幕继续没有可靠时长，不能支持连续覆盖或提醒/参数。
- `VisualSourceContext`只存在于本次内存，冻结source ID、整理input binding、
  完整投影视觉快照及上下文副本；不打印repr。调用者必须提供当前整理binding。
  错来源、缺上下文、过期binding或投影变化时在HTTP前拒绝，保留动作待确认。
- 上下文与动作成员、完整语音共同计入原64000字节容量；不截原句、删未知项或
  提高上限。超容量沿用不可用结果，不用空上下文冒充保真成功。
- 现有输出schema、成员完整性、合法提醒选择、时间连通、编号/侧别/变式/轮次、
  参数冲突、原始来源范围和待确认规则不变。准备/讲解不能填补示范间隔。
  真实68/208秒是否改善不得用传递测试推断；实际样本为67.83/207.77秒。

## 验收与限制

沿用确认过的Provider HTTP→整理→候选融合公共边界。原私有诊断仍在默认路径
复现两个视觉上下文缺口，它不因新增开关自动变绿；新版显式路径须确认上下文
确实到达HTTP，不能只凭失败后原候选仍在的降级输出判成功。

正例完整保留条件和否定、原时间，准备不变动作；即使模型提出同次示范，
原时间间隔仍拒绝。普通/完整语音两路径、默认关闭、过期绑定、改动投影、
缺上下文、组合容量及全链路一次绝对时间偏移均需检查。旧来源、动作参数与
提醒保护回归、完整check/E2E/API及Standards/Spec后再决定真实验证。

这只修复可复现的上下文传递缺口；新教学衔接合同仍待用户确认，208秒最后视觉
请求超时仍是独立限制。不能据本批宣称真实去重、提醒语义或整体goal完成。
