# 内容角色判断与仅来源关联

状态：已接受，依据当前任务用户对上一条方案的明确同意。关联 #7。

扩展 ADR-0053 的现有一次文本融合调用，不新建模型阶段、不增加视频分析调用。
正式动作仍按时间重合、编号一致、参数兼容的规则合并同次示范；不同时间的真实
再次执行保持独立。只有明确预告/回顾允许跨时段关联到正式动作，且仅作为来源。

## 输出与保守边界

- 每组仍有 member_ids、name、relation；新增 content_role（exercise、preview、
  recap、equipment_setup、non_training_gesture、uncertain）及 related_member_id。
  关联目标是正式动作组内一个原始观察 ID，不是模型虚构的动作或分组 ID。
- 所有输入 ID 必须且只能在某组成员中出现一次。关联目标不计作再次成员归属。
  丢 ID、重复 ID、非法目标、关联链/环等结构错误使整次融合保留全部候选并提示失败。
- exercise 仍遵守 ADR-0053 的执行合并校验。uncertain 或 relation=uncertain
  均保留原候选待确认，不得删除或当作可靠参考关联。
- 首批仅对有视觉描述的视觉观察执行预告/回顾关联或非训练排除。语音明确训练
  要求及已标为 follow_along 的观察不因该裁决消失；冲突时保留待确认。这是首批
  的保守覆盖限制，不宣称处理所有语音预告或纠正所有上游角色误判。
- preview 必须在目标之前，recap 必须在目标之后；明确编号不得与目标冲突。
  参考参数与目标冲突时不隐藏该观察，保留待确认；参考参数缺失或互补时也不能
  补入目标参数。目标若未通过正式动作校验，关联观察同样保留待确认。
- 成功关联只追加原始证据时间段。主动作名、参数、主要回看片段、确认状态不变，
  不扩大播放范围，不通过增加证据类型提升可信状态。来源快照沿既有格式保留；
  不新增用户可见角色枚举或数据库架构。
- 方案条目以可选 sourceEvidence 保存既有 EvidenceSpan 格式的完整来源快照，
  接受、编辑、存档和恢复不得丢弃关联时间段。旧方案允许缺省，不改变表或索引。
  本批不新增来源选择器，默认回看仍使用原有主片段。
- 明确 equipment_setup / non_training_gesture 不进入候选；热身、活动度、放松、
  真正示范和真实下一轮不得归入这些角色。身份不清不等于非训练，默认待确认。
- 模型不重写训练数值，不读取媒体或用户档案；超时、异常、无效结构、超预算和
  取消的行为保持原合同。分类输出有错仍可能产生误排除，自动测试不能证明模型
  语义准确率，必须单列真实复测与剩余风险。

## 2026-09-19 迁移补充

同一次正式示范的参数冲突按 ADR-0054 保留数值与来源，不再要求参数兼容才能确认动作身份。参考角色的参数仍不能污染正式动作。
