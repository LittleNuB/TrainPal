# 方案与训练页面使用渐进披露和单一主操作

状态：已接受（2026-07-22）

2026-10-09：[ADR-0085](0085-sport-ai-mobile-visual-and-editing-direction.md) 将主要训练数字
改为单动作卡内展开编辑。来源和低频详情仍按需打开。暂停入口层级已由 ADR-0084 更新。

移动方案页只在顶部显示方案摘要、覆盖提醒和一张非阻塞的 TrainPal 教练卡，动作列表默认仅展示名称、组数、次数或时长和休息；点击动作后才通过 Bottom Sheet 编辑完整字段、查看来源片段、证据和最多三条动作要点。底部固定“开始训练”作为唯一主操作，排序、复制、删除和手工新增降为次级操作。训练页按“视频、当前任务、单一主操作”组织：视频保持原始比例并使用 `contain`，中部只显示当前动作、组次、目标和最多一条要点，底部按钮随状态变为“开始本组”“完成本组”或“准备好了”，暂停、跳过、调整和提前结束进入更多面板。小猫教练不覆盖视频，训练阶段位于控制区旁，休息阶段才与倒计时成为视觉中心。该选择减少了首屏信息量和误触风险，同时保留用户随时深入查看与调整的能力。
