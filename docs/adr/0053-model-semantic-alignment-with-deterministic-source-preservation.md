# 模型语义对齐与确定性来源保留

状态：已接受，2026-09-12，依据当前任务用户确认；关联 #6。

补充：ADR-0051 扩展内容角色判断及预告/回顾的仅来源关联；正式执行合并仍遵守
本 ADR 的共同时间交集要求，跨时段参考关联不等于合并真实再次执行。

用户明确批准新增一轮文本模型判断：时间重合但名称不同的语音/视觉候选是否属于同一次示范。复用现有 Ark Provider 和文本模型，不更换视觉/ASR Provider，不重新传原始媒体，不上传用户档案。

此决定取代 ADR-0048“不增加额外模型调用阶段”对候选融合的限制，以及旧融合合同“名称相等”和“语音值优先”的做法。原有媒体、参数来源、待确认和执行边界不变。

## 模块接口与责任

- 输入：上游结构化动作名、绝对时间段、原参数、来源类型、既有动作编号、角色及最多 600 字符的视觉动作描述。不发送原始转写、文件路径、凭据、个人档案或视频。
- 模型一次返回完整候选分组、中文名称或 null，以及同次示范/不确定关系。每个输入 ID 必须且只能出现一次。
- 时间重合为重要线索；模型综合动作语义、姿势、器械和编号判断，不把同一时间直接视作同一动作。
- 代码要求组内存在共同时间交集、明确编号不冲突、参数兼容。不同时段的再次执行不可合并；同名不同变式由模型保持独立。
- 2026-09-14 实测补充：相同编号的明确写法（如 `4`、`动作四`、`#4`）在护栏中按相同序号比较，原输入不改写。仅识别完整阿拉伯数字或零至十的单字中文数字及 `动作` / `#` 前缀；带左右侧、轮次、字母或其它修饰的标签保持原样，不抽取其中数字强行等同。该归一化只消除误拦，不替模型决定动作身份。
- 合并保留全部原始证据时间段；参考播放选择一个原有视觉段（无视觉时原语音段），不拼接或扩张时间。参数只能来自输入，不能由模型重写。
- 参数冲突或不确定分组保留原候选并标待确认，显式告知未合并，不丢弃任一冲突值。
- 模型失败、超时、无效分组或超出文本预算时保留原候选并提示语义去重未完成。取消仍传播，不能被降级吞掉。
- 默认本阶段最多 20 秒，并受整次运行剩余预算约束；输入最多 200 条且序列化不超过 64 KB。超过时显式回退，不截掉候选。这些为初始运行护栏，不是已证明的性能指标。

## 验收接口（用户已确认）

1. 模型融合模块输出：同次示范合并、双方证据保留；不同变式/编号/后续执行不误合并；失败不丢候选。
2. 最终方案编辑器：接受结果后的动作数量、中文名、参数来源与参考片段符合融合输出；未接受前不改旧方案。
