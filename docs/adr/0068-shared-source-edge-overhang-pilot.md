# 共同说明首尾超出画面的隔离试点

2026-10-04，关联 #6/#37，补充 ADR-0063。共同旁白11.68–14.64秒与两个独立
视觉观察12–13、13–14秒无法通过原完整覆盖条件；公共接口反事实已证明这是
独立的程序接纳限制，不代表模型已经正确提出共享关系。

上述收益和误消除真实执行的风险已向用户说明，用户随后授权当前及后续操作。
本决定只批准默认关闭的隔离实现和验证，不能自动启用产品或视为质量通过。

## 决定

- 新增显式内部选项 `allow_shared_source_edge_overhang=False`，仅改变已有
  shared_sources 的视觉时间接纳条件。没有 source_context_model 时仍无共享
  来源路径；工厂、环境、公开API、持久化与默认提示不接入。
- 原默认仍要求视觉联合完整覆盖旁白。试点改为每个目标都与完整旁白正重叠，
  目标视觉之间连续无内部空隙，且旁白范围内没有目标组之外的视觉动作。
  不新增秒数容差、不吸附边界、不截短旁白、不调整原视觉或语音时间。
- 模型仍必须明确提出多动作共同说明并引用本次同源完整语音原句；至少两个
  独立、不同名称、通过既有保护的教学动作各自保留。不新增模型调用，不由
  程序猜测共享关系。模型未提出时，新旧选项结果相同。
- 原句完整覆盖、同源快照绑定、每观察恰好一次、目标独立、未知引用拒绝、
  跟练/轮次、编号/侧别/变式和参数冲突等既有规则不变。名称不同与时间连续
  不等于语义已证明；模型误判仍可能消除真实第三次执行，必须真实对照。
- 共享语音带训练参数仍拒绝；目标参数、播放选段、待确认状态不变。保留整段
  来源，来源关联不增加独立证据票数，不自动搬运共享说明里的提醒。

## 验证和限制

沿用 Provider HTTP → 候选融合公共接口，先复现首尾超出时多出第三候选，再
验证试点只移除共同说明的独立执行，保留两个目标和完整语音出处。保持内部
空隙、第三动作、仅接触不重叠、参数、无完整原句、跟练、相同目标、被拒绝组、
提醒越权等反例；关闭态保持原行为。完整check/API/E2E及双轴审查后本地提交。

真实验证须在同一份瞬态上游和同一模型响应上比较旧/新时间条件；模型没有提出
共享说明时必须报告无效果。独立动作减少、参数/来源丢失、提醒错误搬运或确认
状态放宽均为失败。通过合成反例不代表消除真实重复或完成整个Goal。
