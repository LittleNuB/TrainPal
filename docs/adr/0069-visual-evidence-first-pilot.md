# 视觉证据先行的隔离试点

2026-10-04，#6/#37。用户明确允许视觉先提取动作与字幕，再增加一次文本调用
整理参数与提醒。仅授权隔离实现与验证；正式工厂、Provider、演示入口不切换。

- 每个原视觉块仍只读一次。先输出身份、编号、角色、范围与完整必要字幕，
  不生成训练参数或筛选提醒；字幕保持VLM读取结果身份，不冒充独立OCR。
- 全片读取后一次文本请求整理字幕，ASR原句只提供上下文，不可生成视觉出处。
  不增加重试或分批请求。容量不足明确失败，不能截断条件、否定或冲突。
- 引用ID由本次run/source/version及完整输入内容绑定。整理模型不能新增、
  删除、重命名、合并动作，也不能生成原句或时间。每条字幕恰好判定一次。
- 训练安排与选重量条件分开；同动作多条训练安排分别保留参数及完整出处，
  后续必须保留冲突，不能先任选一条。未知用途不转训练参数。
  同句兼有训练安排和技术提醒时两者可并存且原句完整。单句多阶段要求无法用
  一套参数表达时保持未知并保留原句，不能任选一套；后续融合不得掩盖此缺口。
- 提醒需引用原句、归属支持引用和明确支持路径；时间包含或上游关联本身不
  证明归属。模型判断仍需真实语义验收及现有后续保护，不作为自动确认依据。
- 第一纵切返回内部的“动作+逐条来源判断”，不投影进旧方案，不改公开
  API或存档。整理失败无可用整理结果；原读取证据只在调用方内存中保留供
  错误处理，不冒充完整候选成功。取消传播，不保留转写/响应文件或内容日志。
- 后续接入融合时只能确定性展开来源观察，不能创造训练动作；须单独验证
  多要求冲突、相同来源重复不计票、编号/侧别/变式/再次执行及原时间保护。

第二纵切以显式 `evidence_first_ark` 接入隔离编排，不改工厂默认。原视觉块各读
一次，块内观察和字幕只加一次块偏移；完整读取结束后至多一次整理，随后沿用
原融合。任一读取失败不再读取后续块，也不运行整理或融合；整理失败不回退为空
参数。原片仍不得超过300秒。ASR原句和逐条字幕只在本次内存中使用。

内部投影每个观察只形成一个视觉候选，逐条参数作为附属来源要求；冲突值保留
精确字幕时间，播放范围仍是动作范围。重复视觉来源不构成独立确认票。未知字幕
用途显式保持待确认并给缺口警告，不能由语义模型通过预告/总结分类排除，也不能
成为共同来源排除。此状态不把原句写入公开合同或永久存储。已有身份保护仍依赖
明确编号/限定词；没有身份限定词时，异名是否同动作依赖模型语义判断，不宣称
存在覆盖所有侧别/器械的动作名称解析器。

沿用Provider HTTP公共边界测试：真实发送schema与应用校验、原句/时间保真、
非法引用与输入漂移、非有限数字、范围、取消、超时、单次调用、冲突不丢。
再完成整链路专项、完整check/E2E/API、双轴审查和同版68/208/39真实复评。
本ADR未声称新视觉合同更准确或整个Goal已完成。
