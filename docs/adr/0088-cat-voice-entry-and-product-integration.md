# ADR-0088：B 小猫语音入口与本轮整合

状态：2026-10-18 用户选择 B 方案，授权完成本轮更新、验收后合并主线，并同步 README 文案和图片。

## 呈现

- 接替 ADR-0087 的“呼叫 TrainPal / 免手模式”按钮组，改为带麦克风与“跟我说”文字的小猫入口。沿用用户确认的七猫风格，未选择时显示麦克风，不擅自替用户选猫。
- 入口和训练主按钮处于同一底部操作区，分别占位。桌面在训练控制区内展示，手机为固定底部操作区。
- “语音唤醒 · 开/关”明确显示当前状态。主动开启、语言包下载、权限失败和不支持状态保留，离开/隐藏页面后关闭。
- 点击入口直接进入单次语音流程；首次先解释并取得本次语音使用确认。文字输入是展开面板内的次级入口。
- 点击或喊 TrainPal 后打开底部面板，训练暂停；等待、正在听、查找、结果、保存、失败各有明确状态。每次只处理一个请求，展示一张可预览/确认的结果，不添加聊天记录。
- 使用原生 dialog 阻止背景误触，支持 Escape、关闭按钮和焦点返回入口。取消后保持暂停，只有明确确认或继续指令恢复训练。
- 小猫只保留一个训练入口，训练要点继续展示，去除与入口重复的陪练头像。

## 功能边界

语音可暂停、继续、回退 5 秒、查找已有片段、预览、确认、取消与关闭唤醒。训练量仍在动作卡片中直接修改或在个性化审阅中修改。不更换内容理解 Provider，不自动启用隔离模型实验，不新增收费评测。

2026-10-20 用户追加授权“TrainPal，完成本组”：明确口令就是次数型动作的完成确认，无需再次点击。唤醒暂停后的指令绑定当前会话版本、动作与组次，记录成功后关闭助手并按原流程进入休息、换动作或结束训练；普通/放大模式一致。准备、倒数、休息及计时动作不能因此被记为完成，重复或迟到指令不能记到下一组。保留原按钮与主动开启唤醒要求。

## 整合与验收

本轮包含之前已获批准的运动视觉、折叠编辑、可编辑个性化、训练流程、文案清理和语音入口更新。主线缺少这些功能的前序依赖，整合时一并核对运行依赖；独立评测工具和模型试验不作为默认产品路径。

验收覆盖公开页面和组件接口：320/390/768/1440 视口、短屏/大字、键盘与可访问性、单次语音授权、本地唤醒、取消/迟到/过期提案保护、完整训练旅程、lint/typecheck/build、单元与 E2E。自动语音事件验证交互和状态机；真实口音、噪音、手机麦克风另行列明，不把模拟事件写成真人验收。
