# 独立字幕时间轴隔离试点

2026-10-04，用户确认动作观察与字幕独立提取，再由一次文本调用判断用途和归属。
隔离试点基线 `b0bc9dd`，#6/#37；不接工厂、公开API或演示入口。

## 决策

- 显式 `independent_visual_captions=True` 才启用新读取合同；旧试点保留作为对照。
  视觉同次请求输出独立 observations 与 captions，不为字幕预先分配动作。
  各自保留完整时间；字幕可跨动作边界，但必须在该视频块内。不得裁短字幕或
  扩大动作范围以凑包含关系，不增加VLM请求，不做自动重试。
- 块时间仅偏移一次。全片整理仍至多一次，ASR原句仅作上下文，不能生成视觉
  引用；已有run/source/version及完整输入哈希绑定、逐字幕恰好一次判断不变。
- 整理模型只能引用本次已有动作及字幕ID，不能生成/重命名/合并动作或改时间。
  上下文支持可来自同片独立字幕，包括章节及前后切换信息，不再要求同观察嵌套。
  有效训练要求/提醒本句仍须与目标观察正重叠；完全在外的字幕只能作上下文，
  不能自动搬运到前后另一轮。重叠是必要时序保护，不是归属证明。语义归属仍需
  完整点名或有界教学支持路径；冲突、转场残留、预告或无法唯一定位时未知。
- 未归属字幕单独保留于本次内存，不塞给某个动作。未知字幕覆盖到的观察保持
  待确认；编排给出未用于训练提醒/参数的缺口警告，包括未覆盖任何动作的未知。
  未知不产生参数、提醒或独立确认票，不允许模型通过非训练/预告分类隐藏缺口。
- 有效参数要求仍逐条保留精确字幕出处及冲突。新投影的提醒可以跨动作边界，
  在原融合再次选择通过后按原句原时间保留；不扩大播放范围。该重叠校验例外仅
  对新独立字幕投影生效，旧视觉/语音提醒的完整包含保护不变。
  原字幕、支持字幕和上游归属假设在内存中传给融合复核；不只传“已挂在动作下”
  的提醒。支持引用不是独立真值，融合不能从支持字幕生成新提醒。
- 非法绑定、未知/重复引用、非训练目标、非重叠目标、来源时间越界或混合读取
  合同均失败关闭，不静默删除坏字段获得成功。模型合法引用仍不等于语义正确。
  整理请求的输出schema也列出本次绑定、动作与字幕ID的有限选择，并区分有效归属
  与context/uncertain的空归属结构；不再只靠提示词说明和返回后拒绝。原restore
  校验仍保留，schema合法也不能替代时间、归属、参数用途和重复引用校验。

## 验收

Provider HTTP与候选编排公共边界，合成案例先验证：跨边界原文原时间保留、
独立章节上下文、未知转场不进提醒、同名后续轮次不误挂、旧路径不放宽；
保留非法ID、绑定、容量、schema、取消、失败停止与参数冲突回归。
完整check/E2E/API及Standards/Spec审查后，真实68秒先验证新合同能否跑通，
再按结果推进同版68/208/39及重复质量复评。未通过不能宣布Goal完成。

本试点不保存转写/响应/字幕原文，不改旧方案、训练状态机或正式Provider。
只在显式开启时替代ADR0069的嵌套字幕与同观察支持约束，其余边界仍适用。
