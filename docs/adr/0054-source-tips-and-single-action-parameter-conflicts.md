# 来源要点与单动作参数冲突

状态：已接受，2026-09-19 按本轮已批准迁移计划整理，关联 #23。

同日后续决定 ADR-0055 为时间校验加入连续重叠教学分块例外；通过该例外的同次示范也适用本文的参数冲突保留规则，不因时间校验变化而静默选择数值。

本批迁移原 watch-workout 规格的分析与证据部分，后续训练呈现与语音片段调整独立交付。补充 ADR-0053/0051：模型确认同次示范且共同时间交集、动作编号保护通过后，参数冲突不再拆为多个重复动作，改为一个待确认动作及带出处的参数备选值。身份无法确定、不同编号和真实再次执行仍保留分项。不得平均、投票或静默丢弃冲突值。

每个动作最多三条来自明确语音或画面字幕的要点，带类别、绝对时间和证据类型。语音要点核对带时间转写中的原文；字幕要点仍依赖视觉模型判断，不能声称人工验证。无可靠内容返回空。原始转写和模型原文不持久化。要点和已有参考范围随基础方案保存、归档、刷新和复练保留，旧数据字段可缺省。

本批不启用网页或通用知识补充。保留 ADR-0020 的来源标签合同，不把一般知识标为视频内容。不改变训练状态机、正式 Provider、分析上限、云端或发布配置。
