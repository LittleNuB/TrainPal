# 原文提醒保真与文字动作参考库试点

状态：2026-09-27 用户批准两线并行、仅文字知识库，以及先采用原文摘录的保守提醒版本。
关联 #37/#23。实现基线 28e4644；本地首批，不代表发布或真实识别质量已通过。

## 决定

知识库只能辅助动作身份判断，不能成为视频中的动作、训练参数、出处或提醒的证据。
不引入图片、动画、向量数据库、Agent 节点、新 Provider 或额外自动模型请求。
文字参考与来源提醒独立验收；原文缺失不能用常识重建。

本轮训练提醒的目标是保留视频原话，拒绝自由改写；含义或动作归属不确定时不播报，
保留待确认，不阻塞其他训练。完整原句、时间和动作绑定必须能核对。
这份决定不宣称当前代码已实现该目标的全部环节。

## 首个原文切片：语音内容匹配

取代 ADR-0054 中仅用连续子串核对语音要点的实现方式。上游提示版本 1.7.0
只允许选择一个完整 ASR utterance 的正文（只移除首尾空白），不自行摘词、
拆逗号、去标点或串接句子。全文超过现有 80 字限制就不输出，不截断。
程序逐字相等验证，要求唯一匹配且完整转写时间位于动作及分析窗口内。
模型提出的提醒时间必须位于该转写时间内；实际来源范围由原始 utterance 回填，
不能用模型臆造的更窄时间代表整句话。

保留的原句与来源通过现有 tip_evidence 进入融合。归属审核沿用 ADR-0057，
只选择 ID，不重写原话。被拦提醒不得由融合模型重新放行；动作和参数仍可正常输出。
原始转写仅在本次运行内使用，不新增永久保存，不改旧方案。

这是转写保真，不是原音频准确性证明，也不是语义完整性证明。
ASR 可能把否定、条件拆到相邻 utterance，或本身识别错误；完整单条也可能指向
其他动作。提示词要求对这些情况省略提醒，但本切片尚没有独立证明模型会遵守。

## 首个知识库切片：审核文字种子

固定 hasaneyldrm/exercises-dataset 的 commit
7455efae41b330c265e7cd4b78dfa848e7ce5ebd，仅取 8 条文字记录。
保留源英文说明、记录 ID、器械及许可；中文名、别名和区别说明单列，
标记 agent_reviewed_not_expert 与 reference_only，不包装成人工专家标注。
不复制上游媒体、媒体地址或未经核对的整套中文翻译。源数据也不是金标准。

查询公共接口是 `ExerciseReferenceCatalog.lookup(name, equipment=None)`：
只匹配已审核别名，统一大小写、全半角、空格与连字符；不做模糊或子串匹配。
返回最多 4 个参考候选，按来源 ID 排序而非置信度；命中超过 4 个就不返回，
避免截掉其他变式造成唯一匹配假象。未知侧别、变式或额外限定不能降格成普通动作。
器械可显式缩小范围，不允许覆盖未知名称。种子不可变、ID 唯一，拒绝额外媒体和处方字段。

融合构造器接受可选 `reference_catalog`，默认关闭，产品工厂不加载它。
实验启用时沿用同一次文本融合请求，把候选名称、器械、区别说明及版本单列为
`exercise_reference`；不发送通用训练说明，不替换原始观察，也不新增模型请求。
提示明确参考不是视频事实；来源 ID 不能用作提醒 ID。原有参数、时间、编号、
轮次和提醒证据校验照常执行。启用不代表模型能够正确使用参考。
联合输入仍受 200 条观察 / 64,000 UTF-8 字节限制；超限不截断证据、不发请求，
原动作全部保留待确认。启用参考可能更早触及预算，这是实验的已知限制。
