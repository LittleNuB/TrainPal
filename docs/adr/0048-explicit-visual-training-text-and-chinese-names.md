# 可读字幕进入训练证据，动作名称优先中文

状态：已接受，2026-09-08，依据当前任务用户确认。

2026-09-12：候选融合的额外文本模型调用及参数冲突处理由 ADR-0053 取代；其他视觉/中文名称合同保持。

补全现有 Provider 的视觉证据合同，使可读字幕中的训练参数与明确动作编号进入确定性融合；显式非训练内容不进入候选。保留原有 Provider、模型及运行架构，不增加额外模型调用阶段。

次数范围通过候选 `reps`（下限）与可空 `reps_max`（上限）表达；只有确切值才直接成为视频来源的执行值。范围由训练编译规则选择下限，标记 `rule`，并保留原始范围供用户复核。这不是用户必须遵守的训练量边界。

语音和画面参数互补，冲突采用语音明确值并要求确认。单一视觉仍待确认。名称优先简体中文，保留可见姿势、握法、器械和方向差异；精确已知英文名称可以本地映射，未知术语不模糊猜译。此决定替代语音 Skill 关于必须原样保留英文展示名的旧要求，不改变来源信息真实性要求。

不修改已有草稿或训练记录。所有新增媒体派生材料和模型响应仍在终态清理，公开结果不携带完整字幕、账号或内部分类。
