# C 视觉更新与本机分析配置

状态：已接受，2026-09-08。依据当前任务中用户对完整 C 参考图的确认及真实 Provider 验证授权。

## 视觉

采用暖白、灰绿、陶土色与墨绿正文，取消纸张网格、装饰标签和夸张标题。训练页也采用浅色背景，实际视频保持深色底和完整画面。此项明确替代旧移动体验 brief 及 ADR 0042 中关于网格、胶囊和深色训练舞台的视觉描述，不改变其问卷、七猫资产、无障碍与沉浸流程约束。运行中的 Vue 页面是实现真源。

首页仍以选择健身视频为主；五个受控来源折叠为次入口。桌面使用独立侧栏与宽屏布局。详见 `../design/trainpal-c-implementation-spec.md`。

## 本机 AI

真实复现表明原 20 秒分段超时会中断正常视觉调用：10 秒最小画面用时 16.5 秒，60 秒画面用时 46.8 秒，均可得到有效结构化结果。因此 `pnpm dev:api` 采用仅监听 127.0.0.1 的 development 启动入口，将默认单分段／证据／整次预算设为 90／590／600 秒，仍允许显式进程环境变量覆盖。直接生产入口与已有生产预算不变；不改变 Provider、模型、顺序分段、并发槽、清理、取消或 partial 降级机制。

前端本地视频大小限制以当前 API 能力为准，可用构建时 `VITE_UPLOAD_MAX_BYTES` 进一步收紧。Docker 发布构建仍默认 19,000,000 字节，保留 CloudBase 请求封装余量。本机 208 秒授权视频约 28 MB，不应受历史云平台限制阻挡。

代价：真实视觉分析可能需要数分钟。这不是满足旧延迟目标的证明，也不是生产上线验收。不得通过缩小覆盖范围或伪造结果来掩盖耗时。

用户仅授权本机已有凭据、现有收费 Provider 及指定四个本地视频；未授权部署、云资源操作、购买、推送、PR 或合并。
