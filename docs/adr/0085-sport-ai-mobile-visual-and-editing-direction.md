# ADR-0085：采用轻量运动视觉与可编辑的 AI 方案工作区

状态：视觉与交互方向已接受，2026-10-09。用户在完整 18 屏图册上确认“通过，制定执行计划”。代码实施按执行计划推进。

## 决策

采用白色/浅冷灰底、深蓝文字、青绿色主操作与正式七猫资产。页面移动端优先，减少装饰和同时展开的信息；AI 通过视频整理、结构化上下文与可审阅建议呈现。

训练方案默认收起动作，只展开正在编辑的一项；主要数字可直接输入和加减。视频依据在单独面板查看，低频完整编辑保留可达入口。AI 提案可先在审阅副本中手动改数字，再确认应用。快速开始将预设方案和示例视频分析合并到同一面板。

## 对历史决策的覆盖

- 接替 ADR-0047 的暖白/灰绿/陶土色视觉，及旧 C 设计文档中与本轮参考图冲突的视觉要求。
- 接替 ADR-0028 中“完整参数仅通过 Bottom Sheet 编辑”的主编辑呈现。单项卡内编辑成为常用数字入口；来源与次级编辑继续按需展开。
- 小猫以当前页面的局部品牌/陪练元素呈现，减少常驻大卡片；有浮动能力的入口仍保留收起、键盘与遮挡避让。
- 未确认风格时不以图片中的示例猫代替真实用户选择。
- 训练的暂停、自动倒数、下一动作准备等继续按 ADR-0052/0084 执行。

## 个性化实施约束

目前页面没有接入训练经验和反馈，也没有可编辑的提案审阅副本。这些是本轮明确需要建设的能力。

沿用 ADR-0046 的自动调整边界和来源保护，以真实结构化上下文扩展策略；GYMTI 不直接决定训练量，风格不决定数值。审阅中的用户修改保留为 user，未修改的自动建议为 personalized。新的上下文/审阅协议在实现时记录版本与迁移规则，遵守 ADR-0019 的基础方案失效与上下文提示规则。
