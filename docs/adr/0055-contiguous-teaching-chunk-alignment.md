# 连续重叠教学分块的有界合并

状态：已接受，2026-09-19，用户在 #31 后明确允许试行；关联 #6，依赖 #31。

## 决定

对 ADR-0053/0054 的共同时间交集校验增加一个保守例外，而非取消原校验：模型在现有一次文本调用中明确返回 `same_demonstration` 且角色为 `exercise` 时，连续重叠的同次教学视觉分块可以合并。修改确定性融合校验，并在融合提示词 2.3.0 中同步说明该例外；不增加调用、不切换 Provider、不改模型输入输出合同。

例外必须同时满足：

1. 至少两个视觉观察，全部明确标为 `teaching_demo`；组内没有 `follow_along`。角色未知的视觉段继续使用旧共同交集路径。
2. 视觉段按开始时间排序后，每段都与此前已覆盖范围有正长度重叠；仅首尾相接不算，不容许间隙，也不允许语音替视觉补桥。
3. 每条组内语音观察都与至少一个组内视觉段有正长度重叠；不能带入时间不相关的参数。
4. 保留原编号身份校验，包括左右侧、轮次等修饰；不同编号不可合并。模型判断为不同组或不确定时，代码不主动跨组合并。
5. 组外任何训练视觉观察与该视觉连续范围重叠，均保守阻止例外，包括身份未知或模型归为预告/回顾的观察，避免跨越可见动作边界。语音组外观察不作为视觉边界。

视觉时间覆盖只用于验证连通性，绝不写回为新的来源片段。默认回看仍选择最长的原有视觉段，等长选较早开始的一段；因此合并后不保证一次播放覆盖全部教学。原始证据保留，播放选项仍遵守既有最多 12 项合同，视频要点最多三条。参数冲突依 ADR-0054 保留一个待确认动作和全部冲突数值及出处，不静默裁决；确认状态规则不放宽。

## 验收与限制

沿用 ADR-0053 用户已确认的融合公共接口。先复现 `0–40 / 30–60 / 50–75` 被拆为三项，再验证可以合为一项；无共同交集但由嵌套段连接的教学同样有效，输入顺序不影响结果。必须保护编号、变式分组、跟练轮次、不确定关系、视觉间隙/首尾相接、宽泛旁白、无视觉输入、无关语音和组外动作边界，保留参数冲突与原始范围。

仅合成证据测试不能证明模型的语义判断准确。若上游错标教学角色、漏掉其他动作或模型错判同次教学，仍可能误合并；真实效果需另行复评。本次不新增收费复测、不改旧方案、不开放网络、不合并或部署。
