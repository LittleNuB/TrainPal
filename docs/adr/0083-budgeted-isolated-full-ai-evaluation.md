# 全 AI 评测的隔离与费用冻结

状态：已接受的实施边界，2026-10-07；尚未完成全矩阵验收。
关联 #5/#6/#37，承接 ADR-0082。完整规格见
[评测规格](../design/trainpal-flash-full-evaluation-20261007.md)。

## 决定

- 独立 `evaluation.build_evaluation_app`，真实调用前要求干净提交和不可覆盖的
  冻结回执。公开 API、正式／验收工厂与 15176／15177 不变；首批运行脚本
  临时绑定 127.0.0.1:15178，完成后正常关闭应用及连接。
- Mini 保留当前分析路线。Flash 沿用已接受的证据优先试点和原采样／接收校验；
  本轮两配置统一沿用当前 Settings 的运行／证据／分块超时，记录配置摘要。
  不把多模态输入与工作流差异全部归因于模型，不放宽来源绑定和确认规则。
- 所有 Provider 零自动重试。GYMTI 只在隔离环境显式启用，发送合成且合同
  允许的稳定 ID；两个对照配置均关闭思考并限制 1024 个输出 Token。
  Flash Chat 接收须回显正确模型和正常结束；无有效输出仍走既有规则降级。
  正式 GYMTI 仍遵守 ADR-0044 的供应商与留存门槛，不伪造其确认开关。
- 独立费用账本在每次模型／ASR 请求前预留保守上界。短同步临界区和文件锁
  共用 50 元总帽，不靠结束后回算制止超支。无有效用量／中断保留占用并暂停，
  重启读取旧账本，未结算记录不自动释放。回执不含正文、路径、密钥或帧。
  实际调用的账本固定为项目 `tmp/full-ai-evaluation-20261007/budget.json`，
  不随提交／冻结目录改变；重评新版本不能获得新的50元预算。
- 冻结的 H/A/U 参考与开发样本身份保持；三条新视频、人工关键核验、真机
  语音及提醒和供应商留存核验仍是未完成门槛。后端终态耗时不等于可编辑
  方案／可操作预览的端到端耗时，分别报告。

## 首批操作与剩余批次

在干净提交运行 `uv run --project services/analysis-api python
services/analysis-api/scripts/run_flash_evaluation.py --receipt-root <项目tmp内批次目录>
--freeze-only`，不产生费用。之后显式指定 sample、profile 和已授权本地媒体；
密钥仅运行时文件读取，不加入环境文件、命令行值或公开回执。
脚本不自动重试，也不覆盖同一次回执。

审查修复：样本／配置／重复编号在调用前排他写入 started 标记，终态回执
排他写入并 fsync。中断或终态写失败不删除标记，不允许隐式重跑，不报告
零调用。回环入口使用专用临时 HTTPS 证书，客户端仅在本次连接明确信任
该证书，不修改系统信任、不关闭校验；保留应用的 Secure 会话 Cookie。

当前入口先交付 39/68/208 各一次双配置的首批。完整三次重复、其他六条及
三个文字模块的固定12案例还需独立冻结接入；不是暗中减少原计划。
前一批关键错误或预算暂停时停止相关扩展，定位后新提交另记，不混算。
单次 HTTP 成功、合成测试或回执清理通过，均不能宣称 AI 效果或产品放行。
