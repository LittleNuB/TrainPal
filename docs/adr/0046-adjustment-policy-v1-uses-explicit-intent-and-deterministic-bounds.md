# ADR-0046：方案个性化 v1 使用明确意图与确定性数值边界

状态：已接受（2026-08-24）

## 背景

方案页已有“让 TrainPal 调整这次训练”的产品承诺，但既有实现只进入 GYMTI 与教练风格流程，没有真正生成方案字段差异。直接把 GYMTI 人格或教练风格映射成训练量会把稳定偏好误当成当次训练能力，也会让模型自由数值突破来源和用户边界。

## 决策

- 用户必须为当前方案明确选择 `easier_to_finish | more_challenging | shorter_session`；GYMTI 只可补充解释和候选排序，教练风格不参与数值决策。
- `adjustment-policy.v1` 是纯确定性 Module。它只读取基础方案快照、当次意图、训练经验、结构化动作反馈和安全停止信号，返回完整差异或合法的 `no_change`。
- 只有已经确认且字段来源为 `rule | personalized` 的动作可进入候选。`video | user`、动作名称、顺序、训练方式、来源片段和重量全部锁定。
- 每个动作最多改变一个训练量字段；休息可以同时增加。组数单次最多 ±1 且自动范围为 1–4，次数最多 ±20% 且不超过 ±2、自动范围为 5–20，时长最多 ±20% 且不超过 ±10 秒、自动范围为 10–90 秒。休息 v1 只允许增加，最多 +30 秒、自动范围为 30–180 秒。
- 整份方案预计时长变化不得超过 ±20%。初级训练经验的挑战提案最多改变一半已确认动作。最新 `too_hard | just_right` 阻止该动作加量，`too_easy` 阻止减量并优先进入挑战候选。安全停止信号使整份提案返回 `no_change`。
- 提案绑定方案 revision、内容 fingerprint、上下文 revision、策略版本和意图。相同输入复用已保存提案；方案内容变化使旧提案不可应用。
- 用户整体确认后才原子应用全部差异并把来源标记为 `personalized`。任一原值、来源、revision 或 fingerprint 冲突都拒绝整份提案。恢复基础方案只撤销仍为 `personalized` 的字段，不覆盖后续 `user` 修改。

## 后果

v1 能兑现字段级调整承诺，同时不增加后端、数据库表、队列或模型自由数值。它是产品提案安全包络，不是医学或专业训练处方；上线前仍需要训练专业人员复核与真实用户验证。未来若要修改视频明确值、减少休息或按 GYMTI 自动决定训练量，必须升级策略版本并重新记录决策。
