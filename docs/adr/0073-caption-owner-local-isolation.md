# 字幕整理错误归属局部隔离试点

2026-10-04，#6/#37，基线0d621b7。用户明确允许“字幕整理阶段局部隔离错误归属，
保留原字幕和相关动作待确认，让其他合法结果继续”。本决策补充ADR0070的整批失败
范围，不放宽有效归属条件，不替代ADR0071的融合关联隔离。

- `isolate_invalid_caption_owners=True`显式开启，且必须使用独立字幕时间轴。
  默认关闭，不接正式工厂、公开API、演示或旧方案；无新增请求、重试或模型。
- 先验证wire、绑定和全部字幕恰好一次。当前可局部定位的错误是：合法训练动作ID
  与该字幕没有正时间重叠。该归属不被接受，不修改字幕或动作时间，不猜替代动作。
- 错误行仍须通过引用、参数用途、数值、类别和原句安全校验。未知/重复引用、
  缺失/重复字幕、过期绑定、非训练目标、schema错误仍整批失败；其他行后续出现
  全局错误也不能返回局部结果。最多三条有效提醒等原保护不变。
- 拒绝行保留完整原字幕及时间为未归属uncertain，ownership=unknown，清空这项
  不可信判断的参数、提醒、支持归属。原字幕没有删除，也不搬给邻近动作。
- 错选的目标与所有正重叠观察均标记evidence_incomplete；无重叠观察时也保留
  未归属原字幕及缺口警告。不相关观察不标记，合法判断继续原融合校验。
  相关动作不会因此自动确认；不是承诺所有上游合法提醒一定通过最终归属审核。
- 沿用编排的“部分字幕归属尚未确认，未用于训练提醒或参数”警告。请求内结果
  有固定整数rejected_caption_owners计数（0–1000，与字幕容量一致），序列化排除；
  不增加公开诊断字段，不记录字幕、转写、动作ID或模型原文，不永久保存原文。

## 验收

沿用已确认Provider HTTP→来源判断/候选融合边界。先红后绿验证一条错误归属
不丢原字幕或独立合法判断；相关/无关动作范围、无动作覆盖的原句、融合后待确认、
默认关闭，以及坏归属不能掩盖全局引用/字段错误。完整check/E2E/API、Standards/Spec。
真实68秒先检验是否到达融合与局部隔离计数，再推进208/39和同版重复质量复评。
未通过真实质量门槛不能宣布Goal完成，不把局部隔离当成识别准确率提升。
