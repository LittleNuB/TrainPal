# 用途专用字幕判断格式隔离试点

2026-10-04，#6/#37，承接用户已允许的视觉读取后一次文本整理及继续修复目标。
本项只改变隔离Provider的wire表达，不改变归属规则、失败范围、调用次数或正式默认。
依据见`docs/design/trainpal-organizer-shape-diagnosis-20261004.md`。

- 显式`purpose_specific_caption_decisions=True`，且必须同时启用独立字幕试点。
  默认关闭，工厂/API/演示不接入。旧嵌套及独立字幕格式均保留。
- 每条字幕仍恰好判断一次。context/uncertain只返回字幕ID和用途，不要求模型填写
  空动作、空参数等字段；有效用途返回各自需要的字段。选重量条件不得含参数/提醒，
  tip必须含类别且不能含参数；training_target需有数值，可同时带原句技术提醒类别。
- 请求schema保留本次完整绑定、有限ID、训练目标枚举。禁止未知额外字段；收到
  响应后先验证wire，再将该合法用途没有的字段固定映射回内部null/unknown/[]。
  这不是容错纠正：存在禁用字段、非法值、未知ID、绑定错或缺字段时仍拒绝。
- 继续调用原恢复校验。参数模式/范围、归属、非训练目标、时间、原句安全、
  每动作最多三条提醒、完整覆盖及重复引用保护不变；不补写原文或时间。
- 不增加模型请求/重试，不缓存原文，不保存字幕/转写/模型响应，不修改正式方案。
  当前结构schema更大，成本未证明下降；不得把合成格式通过等同真实质量通过。

## 验收

沿用Provider HTTP→来源判断公共边界，首个合法原句+参数联合输出先红后绿。
覆盖额外上下文字段、空数值、tip含参数、外部引用、旧绑定、重复字幕、非训练及
非重叠目标、错误模式、全非训练时未知保留。旧测试不放宽，完整check/E2E/API及
Standards/Spec审查；真实68秒先检验是否可以到达融合，再决定208/39及重复复评。
仍未授权切换默认；不得为了通过而自动清理模型的不合法字段。
