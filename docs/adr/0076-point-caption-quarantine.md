# 零时长字幕独立保留试点

2026-10-04，#6/#37，基线ab61d36。用户明确同意：字幕起止相等时原样保留，
时间待确认，不补结束时间、不用于参数或提醒，让其他合法结果继续。

- `isolate_point_captions=True`显式开启，必须依赖独立字幕时间轴；默认关闭，
  不接正式工厂、公开接口、演示或旧方案。不增加模型调用、重试或视频时长上限。
- 只接纳原始起止完全相等且有限、位于本视频块内的字幕作为内部时间点记录。
  原文、起止值不改。倒置、越界、非有限数、空白、未知字段继续拒绝整次读取。
  动作观察及其它来源区间仍使用正时长Segment，不降低通用区间的约束。
- 点字幕从可用区间字幕中独立隔离，不发送到整理模型或融合模型，不可作归属
  支持、参数或提醒来源。原文只保留在当次内存证据内，不进入长期存储/公开结果。
- 点字幕仍参与完整输入指纹；更换点字幕后旧整理结果不能复用。全局绑定、
  字幕覆盖、非法引用及字段错误维持现行拒绝策略，本决策不扩大ADR0073归属隔离。
- 分块点时间与正常字幕一样只加一次来源偏移；点落入闭区间的观察标为来源不完整。
  位于相邻动作边界时两侧均待确认，不选其中一个。没有观察覆盖时仍保留点字幕，
  并输出字幕时间待确认警告。合法区间字幕与动作继续原有全部审核。
- 全部字幕都是点时，不购买无可用区间的整理请求；动作仍可进入融合，但相关动作
  继续待确认。只有点字幕、没有动作时不得生成虚构动作。

## 验收

沿用Provider HTTP→整理/融合与完整编排公共边界。先红后绿验证原文/时间保留、
正常提醒不丢、正确动作待确认、分块偏移、点字幕不进入模型/公开候选、默认关闭，
以及倒置/越界/非有限/非法字段/旧绑定仍拒绝。完整check、API、E2E及双轴审查。
真实208秒复评检查是否跨过已定位的点字幕失败；随后68/39及重复质量复评仍是
Goal门槛。本项容错不等于识别正确，不得把点字幕算作已准确定位的证据。
