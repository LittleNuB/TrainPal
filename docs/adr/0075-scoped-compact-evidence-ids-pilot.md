# 保留完整输入绑定的短引用隔离试点

2026-10-04，#6/#37，基线8f1eff4。合成19观察/110字幕的句子级请求共119136字节；
大量重复SHA256前缀出现在正文ID和schema枚举。仅替换这些引用为局部短ID的
等义投影为42460字节，保留全部观察、字幕、上下文及约束；不是实测Token或延时。

## 隔离决定

- `compact_visual_evidence_ids=True`显式启用且要求独立字幕，默认关闭。
  动作ID为a0/a1…，字幕ID为c0/c1…，仅在当前snapshot内有意义。
- 顶层binding_id继续是完整原始输入的SHA256，含run/source/version和逐字数据。
  先验证该绑定，再接受当前完整ID集合的恰好一次覆盖及已有归属/时间/参数校验。
  相同局部ID在另一次来源出现，不允许重用旧响应；未知ID、旧编码引用仍拒绝。
- 不重命名/删除/合并任何动作或原文，不截取字幕、时间或上下文，不增加Provider
  请求/重试，不提高64KB/300秒限制，不更改用途专用wire分支或安全归属规则。
- 不接正式工厂、演示、公开API或旧方案。输出来源对象保持等义，ID只用于本次
  模型输入/返回引用，不作为永久业务ID。是否提升真实稳定性仍需复评。

## 验收

同一合成输入通过Provider HTTP对照恢复结果相等、绑定相等、请求字节减少。
先红后绿，覆盖来源相同局部ID但不同绑定、未知引用、漏/重复字幕、旧编码、
原始逐字/原句/时间/source/version变化、非法时间/NaN/超大正文、配置约束。
完整check/API/E2E和双轴审查；真实208秒重点检查响应能否取得及格式/归属质量，
不能把单次成功归因于短ID，更不能把保护拒绝视作可随意清除。
