# ADR-0090：概括旁白与独立动作的区分

状态：2026-10-19 已接受作用域规则；本地模型验收见 ADR-0091，默认模型不变。

68 秒视频中，一条概括准备阶段的语音与两个独立视觉热身重复编译为三个候选。
融合要求每条已提取的动作观察都归属于一个执行，导致概括说明很难正确归位。
仅追加提示、共享来源关联或更换融合模型均未稳定解决。

## 决定

语音提取增加内部 `content_scope=individual_action|general_context`，由模型结合
完整原话判断。具体动作方式、独立时长/次数要求和实际轮次属于独立动作；仅有阶段
目的、章节概括或器械建议且没有独立执行要求的说明属于上下文。

`general_context` 不编译成额外执行。完整句子仍在本次同源语音上下文中参与用途判断，
不添加视觉证据票数、不自动分配参数或提醒。明确组数、次数、时长、休息或跟练角色
阻止该排除，即使模型分类矛盾也保留原要求。缺失字段兼容旧输入，按独立动作保留。
不按词表、动作名称或目标数量过滤。

增加可选 `ARK_FUSION_MODEL_ID`，仅控制已有文本融合调用；默认沿用 `ARK_MODEL_ID`。
语音理解、视频读取、个性化与其它功能保持各自当前配置。正式 Provider 仍为 Ark。
本地对照仅把文本融合路由到同服务商较强模型，不增加模型调用，也不启用共享来源试点。

## 当前证据

同一份真实上游证据上，作用域区分去掉了额外的概括性候选，保留两个热身、四个正式
动作和可选有氧。Mini 融合仍留片头背景；较强文本模型的普通融合排除了片头背景，
输出七个候选，其中三个缺少充分参数/双源证据的活动继续待确认，耗时约 9.88 秒。
这是同证据对照，不是新鲜完整运行或不同视频的准确率证明。

最初的全新完整运行未稳定复现七项：两次输出八项，另一次把两个热身合成一项、输出六项。
现有默认模型的实际页面运行仍有九项，其中五项待确认。功能链路已完成到训练记录与反馈，
当时识别质量未通过。后续同服务商 Pro 2.1 的视觉 260628 / 文本 260915 配置
连续三次完整分析得到正确七项，其中两次经过浏览器全流程，见 ADR-0091；
保留现有默认模型，显式配置本地验收模式。
