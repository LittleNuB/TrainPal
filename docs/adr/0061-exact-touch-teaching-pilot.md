# 连续教学精确相接的默认关闭试验

状态：2026-09-30 用户批准隔离验证；未批准产品默认启用。关联 #6/#37，补充 ADR-0055。

## 决定

在 `SemanticCandidateFusion` 增加构造参数 `allow_touching_teaching=False`。
只有显式开启的隔离实验允许连续教学视觉段精确首尾相接。默认路径仍执行
ADR-0055 的正长度重叠条件。不添加环境配置、工厂开关、外部 API 字段或前端控制。

实验只放宽连接条件中的等号，不增加容差、不改写来源时间：任何正间隙仍拒绝。
其余条件不变：模型明确判断 same_demonstration/exercise、至少两条教学视觉、
无跟练角色、编号/侧别/轮次身份一致、没有组外视觉穿插，每条语音与视觉正重叠。
不跨越模型分组，不自动合并变式或再次执行。

原始证据、最多 12 个播放选项、最长原片段的默认回看、最多三条合法来源提醒、
参数冲突及待确认状态沿用旧合同。不得扩展默认播放范围或修改用户方案。

## 验证设计

沿用已确认的 Provider 输出 → 候选融合公共接口。先复现精确相接仍拆分的失败，
再补最小实现；覆盖乱序、嵌套、正间隙、身份/角色/模型关系/外部边界反例，检查
提醒引用和参数冲突来源未变。

真实对照中只做一次媒体分析和一次收费语义分组；在内存保留本次请求和响应，
通过外部 HTTP 回放把同一响应交给实验校验。断言请求一致、上游对象未改动，
只保存脱敏计数和参考槽位，不保存转写、模型原文或提示词。
融合提示词保持 2.4.0 不变，以隔离确定性规则影响。因此模型本身仍可能按旧提示
将相接段分组；本实验不能证明新的模型分组策略或产品端到端体验已经完成。

## 风险与发布门槛

相接不是同次动作的语义证据。如果上游角色、编号和模型判断一起出错，仍可能
误合并。需复评 68/208 秒与 39 秒四动作反例，并报告不稳定、遗漏和提醒归属缺口。
候选减少或全自动化通过不能代替真实质量验收。产品接入另行决策；不合并、部署、
改变演示入口或替换 Provider。

## 2026-10-04 隔离试点收紧：缺失身份不能支持精确相接

真实 shared-25 的相同上游对照中，两个不同热身视觉观察首尾相接，普通融合和
完整原句融合都将其与共同旁白放入一个组；旧试点接受合并。局部原片 AI 复核
支持两种不同示范，不能用候选减少解释为质量提升。原模型输出已清理，不把
合成回归称为该次原响应回放；该收据也没有保留热身标签，不能追认其具体标签值。

新增必要条件：只有真正需要精确相接连接的视觉链，才要求组内每条视觉观察均有
非空、非纯空白的原始 sequence_label；仍使用原有全组身份比较，所有标签必须
一致，保留侧别、轮次、变式及可选的严格标题兼容规则。没有标签或只有部分段有
标签时，以固定原因码 touching_identity_missing 拒绝该组并保留原候选待确认，
不透传未审核提醒。不从动作名称、器械词、知识库或语音推造标签。

这收紧 ADR-0061 的显式试点，不改变默认关闭状态、正式工厂、外部接口或原有
正长度重叠规则。代价是无编号但实际同次的相接教学仍会拆回待确认；不能把此
保守拒绝当作完整去重修复。相同标签也不证明同动作，模型误标编号或变式仍可能
错合，仍须真实复评。未新增模型请求、重试或时间容差；生产启用继续未通过。
