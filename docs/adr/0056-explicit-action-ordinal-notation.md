# 完整动作序号的等价写法

状态：已接受，2026-09-19，依据用户同意继续检查编号提取与统一格式；关联 #6，依赖 #33。这里只修复可独立复现的格式误拦，不宣称找到上次真实视频的最终根因。

## 决定

补充 ADR-0053 的编号身份比较：除原有完整数字、零至十单字中文数字、可选 `动作` / `#` 前缀外，接受完整的 `第N个动作` 与 `第N动作`。N 沿用原数字范围；允许语法边界空白。`动作4`、`第四个动作`、`第4动作` 指向同一个编号身份。

必须整串匹配；不截取任意文本中的数字，不消除左右侧、轮次、变式或其他修饰。未支持的写法保持原字符串身份，包含复合中文数词、标点、字母、组数/次数描述以及只有 `第N个` 的标签。不同数字继续冲突。

原始输入、模型输入与来源不重写。等价编号仅移除格式导致的拒绝，仍要求模型同组/同次示范、时间和角色条件通过；不自动跨组合并，不合并真正再次执行。正式分组和参考关联使用相同比较方式；参数冲突、来源范围、待确认和用户值保护不变。

本批不改视觉/融合提示词、Provider、日志、HTTP/SSE、前端或存储合同。不把上游不可靠编号当作可随意覆盖的元数据，也不授权语义模型推翻明确编号冲突。

## 证据与限制

通过已确认的融合公共接口，纯合成 `动作4` / `第四个动作`、重叠片段、同次示范模型输出，修复前仍返回两项及编号冲突；修复后保留一个待确认项和全部来源。该回归只证明格式兼容缺口。
