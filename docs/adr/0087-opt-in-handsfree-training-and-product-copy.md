# ADR-0087：主动开启的免手训练与面向用户的说明

状态：2026-10-11 用户选择“需要完全免手：主动开启后，喊 TrainPal 就能说指令”。实现与工程验证见下方；真实麦克风识别效果需要设备验收。

## 决策

覆盖 ADR-0052 中“不常开监听”的限制，仅允许用户明确开启本次训练的免手模式。默认关闭，不持久化开启状态；隐藏页面、离开训练页、权限失效后关闭，返回不自动恢复。

保留 ADR-0052 的单次请求、来源片段选择、暂停后预览与明确确认、会话和版本绑定。不是聊天会话，不新增对话记录，不将训练量交给片段选择模型。

使用浏览器本地 SpeechRecognition，强制 `processLocally=true`、`zh-CN`，检查本地能力和语言包。需要下载时由用户点击“下载并开启”。不支持时明确提示，并保留现有单次录音和文字入口；禁止回退到浏览器远端持续识别。

只有以 TrainPal / Train Pal 开头的最终识别结果可唤醒。支持一句“TrainPal，重看呼吸讲解”，也支持唤醒后 8 秒内说一次指令。待命语音留在设备，仅查找片段时将指令送到现有 API。识别请求和建议不写入历史。

免手操作：暂停、继续训练、回退 5 秒、查找已有教学片段、预览、明确确认、取消、关闭免手。语音确认必须验证原建议绑定，不能用一次新唤醒刷新旧建议的有效性。切后台或变更动作后不使用迟到的结果。

免手期间停止自动语音提醒，继续显示文字要点，降低播放声音干扰。完整免手只在当前训练页面前台可用，后台和锁屏不是这一 Web 实现的能力。

## 页面呈现与文案规则

- 使用紧凑的“呼叫 TrainPal / 免手模式”入口，文字输入默认收起，常用需求点选；沿用 ADR-0085 的视觉。
- 主页面只说明当前状态、结果、下一步。`真实 AI`、`服务端恢复窗口`、`规则优先级`、`临时文件`等工程解释放在开发文档，不能当作用户提示。
- 隐私说明保留真实的数据去向，用日常语言放在首次语音开启区、折叠说明与“我的 / 数据”中。保留必要的权限、未识别片段、身体不适和删除数据提醒。
- 错误说明应告诉用户发生什么和可以做什么；不直接呈现原始异常、供应商响应或调试信息。
- 新增页面和空态、加载、失败态的审阅均执行这些规则。开发专用设计画廊的技术说明不迁移到产品页。

## 验证范围

测试覆盖本地能力检查、无云端监听回退、显式开启、唤醒前无请求、单次指令、超时、取消、迟到响应、旧建议拒绝和离开页面停止监听，以及原片段持久化训练流程。模拟识别事件用于工程回归，不代表真实口音、噪音和视频外放下的唤醒质量。

当前 Codex 浏览器实际探测：存在本地识别接口，中文语言包状态为 downloadable。下载完成、真实口述唤醒、手机端兼容性与误唤醒率需要单独记录结果。

2026-10-12 工程结果：`pnpm check` 通过（Web 379、API 1703），完整 E2E 58 通过。四个视口均验证文字入口、唤醒前不执行、建议卡片与语音确认；短屏大字编辑与原有训练流程也通过。E2E 识别事件来自测试夹具，未录制用户麦克风、未调用真实模型。15180 全功能本地服务已重新构建并启动，健康检查 200。

接口依据：[MDN 本地语音识别](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API/Using_the_Web_Speech_API#on-device_speech_recognition)。
