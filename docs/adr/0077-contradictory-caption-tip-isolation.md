# 矛盾字幕提醒的局部隔离

2026-10-04，#6/#37，基线c954b1d。用户明确同意：归属矛盾的单条提醒保留待确认、
不用于训练，其他合法结果继续；未知引用等完整性错误仍拒绝整批。

- 新开关`isolate_contradictory_caption_tips=True`默认关闭，依赖独立字幕及用途专用
  格式。仅本地隔离试点启用，不接正式工厂、公开API、演示或旧方案。
- 补充ADR0072/0073：仅tip判断、action_id指向本次已有观察，且ownership为unknown
  或目标为非训练观察时，可局部拒绝。不把这类判断当成有效提醒，不猜新目标。
  null/未知目标、缺字段、非法类别、额外参数、空/未知/重复支持引用仍整批失败。
  训练参数及选重量条件不适用本扩展。
- 发给模型的严格schema和提示不变；接收校验仅在tip分支允许已知观察及unknown
  到达归属检查。原始判断不改写，先完整校验绑定、字幕覆盖、字段、支持和原句安全，
  再把拒绝项保留为未归属uncertain，清空其参数/提醒/归属支持。
- 完整原字幕及时间只在请求内存保留。错选目标与字幕正重叠的观察标为来源不完整；
  无覆盖时仍保留未归属字幕及现有警告。独立合法判断继续原融合审核。
- 沿用rejected_caption_owners固定计数，不增加公开字段或内容日志，不增加调用、
  重试或时长上限。不改变动作合并、编号/侧别/变式/再次执行及参数冲突保护。

## 验收

沿用Provider HTTP→来源判断/候选融合边界，先红后绿验证局部隔离、原句原时间、
合法提醒和参数保留、相关动作待确认、默认关闭及所有全局错误继续失败。
完整check、E2E、接口检查、Standards/Spec；随后真实208秒验证是否到达融合。
容错通过不等于识别正确，68/208/39同版重复质量复评仍是整体Goal门槛。
