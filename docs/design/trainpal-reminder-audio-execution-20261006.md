## 本批实现

- 训练页只执行场次冻结且重新校验的安排，不请求模型。触发前再次核对动作身份、
  来源、版本、训练量和已审核原要点。正文不改写、不截断，当前文字和出处可查看。
- 使用浏览器标记为本机的中文声音；没有、尚未加载或执行失败时保留文字。
  声音后来就绪只用于未来时点，不补播旧提醒。没有新增远程 TTS 服务。
- 准备提示、真实组开始和活跃时间触发分开。按 `ReminderExecution.v1` 留出练习
  间隔和组末静默；长句、不够时间或浏览器声音占用时跳过语音，不塞队列。
- 实际 `onstart` 才标记正在播报并压低视频原声。倒数优先；取消或结束恢复原音量，
  不改训练状态、组数、次数、时长、休息或观看选段。
- 暂停、完成、跳过、明确结束、静音、后台和离页立即取消，不等待训练保存。
  关闭自动提醒不静音视频；偏好保存失败保持本次关闭并显示重试保存提示。
- 页签只保留一个容量受限的执行标记，含场次 ID、完整安排指纹、已处理位置和累计
  已练时间，无正文、录音或模型原文。刷新不重播；坏记录或存储失败只用文字。
  已关闭期间遇到的时点仍消耗，不在后来开启时补播。

## 测试优先修复与证据

通过可见 Vue 流程、公开 store 操作、真实训练执行器和 Dexie 验证，替换的边界只包括
HTTP、浏览器音频、时钟及存储。测试内容是明确合成的视频与要点，不是用户媒体。
模拟语音事件、音量数值和屏幕文字不能证明声音实际可听。

1. 关闭时已遇到的准备提醒重新开启后补播：先失败，消耗该时点后通过。
2. 合法 `30000.5ms` 语音进度刷新被误判为坏记录：先失败；保留有限非负小数精度后，
   刷新继续显示提醒就绪且不重播。没有取整训练时间或放松非有限数值保护。
3. 来源 HTTP 挂起时准备声音已开始，后台监听尚未安装：`pagehide` 和
   `visibilitychange` 两条公开流程先失败。监听前移后即时取消；卸载后的迟到
   初始化不再安装监听或启动计时器。
4. 原全套 E2E 的第二次分析曾收到 `net::ERR_NO_BUFFER_SPACE`，GET 无 HTTP 响应。
   这定位到请求传输失败，不证明 Windows 资源错误的根因已修复，也不证明产品无关。
   新浏览器回归人为断开第一次状态 GET，用户重试恢复同一任务后完成并可刷新读取；
   整个过程仅一次创建 POST、无 DELETE。没有为此修改产品分析逻辑或延长等待。
