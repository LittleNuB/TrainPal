## 浏览器完整复练证据

沿用可见页面、公开 store actions、真实 Vue/Pinia/Dexie/训练执行器及外部 HTTP、
时钟和浏览器媒体边界。没有测试私有辅助函数或模拟内部模块。
分析与提醒响应明确为合成；MP4 由仓库脚本生成，不是授权用户视频或真实模型输出。

浏览器用例完成：合成分析提案 → 核对动作与冲突 → 手动设为 1 组/10 次/休息 0 秒 →
存档重开 → 审核全部五条 → 保存提醒并刷新 → 复制 → 跟练 → 完成记录 → 新建空方案 →
从原记录复练 → 再次刷新和开练。
原方案、副本和记录恢复方案分别使用三个不同身份，每次新身份只请求一次合法安排。
主动新建空方案明确排除“当前方案已经相同”的快捷路径，不以该快捷路径冒充记录恢复。
五条内容、审核状态、参数冲突、用户手动值和提醒缓存经上述流程保留。

首次跟练和记录复练均检查原生视频的解码状态、390×694 自然尺寸、已解码帧计数，
并将实际视频帧绘入 Canvas 读取像素，与生成媒体的已知颜色核对；不只检查控件。
本用例还保留 320/390/768/1440 的无横向溢出、要点审核状态和编辑器可访问性检查。

### 失败尝试没有算作通过

初版测试媒体替身仅返回完整 200 响应，未实现视频字节范围读取。追踪记录显示媒体
请求成功，但浏览器不断寻址、停留在没有当前可用帧的状态。保留原生解码断言，
将合成媒体替身改为正确的 Range/206 响应后通过，不修改产品播放逻辑或放宽画面标准。
尝试直接走测试服务器的媒体地址也未通过：该测试配置的媒体重定向目标不是可播放的
本地 HTTPS 入口；这不是正式服务或实际用户媒体的结论。

另一失败来自测试脚本在异步导航完成前记录旧 `/training` URL，后续并未回到结果页。
改为等待实际 `/result/<id>` 后才记录地址，完整复练通过；没有延长既有 90 秒用例上限。
临时媒体事件诊断已从测试源码删除，未加入产品日志或永久数据。
