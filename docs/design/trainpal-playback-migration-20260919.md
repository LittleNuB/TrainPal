# E 批：有界语音与文字片段调整

依赖 D 批 d7a04de / #28；关联 #24、#21。沿用现有 Ark 与 ASR，不引入新 Agent 架构或 DeepSeek 默认配置。

## 合同

- 用户点击后暂停训练；文字或单次语音请求只选择当前动作已有合法范围标识，不能生成时间点或改变训练量。
- 最多 16 个选项、240 字指令；单次模型调用有 15 秒超时，服务端最多两个并发请求。不自动重试或循环规划。
- 语音在明确操作后采集，说完自动结束，最长 15 秒；现有 ASR 处理临时 WAV 后删除。缺能力/拒绝权限/失败均有文字入口。
- 结果先预览，再确认“用这段并继续”；保留动作、来源指纹、输入代次、场次及版本校验。
- 取消、超时、迟到结果和保存失败不改原选段、不自行恢复。恢复完整教学不直接开练；临时回退不保存。
- 录音、转写、指令和模型原文不进入永久存储或测试材料。服务端响应 no-store。

## 迁移与测试

先迁入公开 HTTP、组件和采集生命周期测试，在未实现基线失败，再迁实现。补充取消后迟到响应、网络超时、保存失败、拒绝麦克风，以及关闭面板时仍在等待暂停的回归。后一项实际复现旧实现会继续恢复选段，现已加入取消代次与待处理锁。

HTTP 请求体仍先限长后解析；OpenAPI 请求 schema 从同一个校验模型生成，前端直接使用生成类型，避免只记录响应而漏掉请求合同。合同测试先失败后通过。完整检查、E2E 和两轴审查结果记录于 PR。

独立审查发现并补测两项边界：音频模块加载或启动卡住时，取消立即释放麦克风；片段保存完成后只同步仍匹配方案、动作及来源的选段，不整份重载草稿，保护等待期间的手动修改。两项均先复现失败，再修复；另覆盖切换方案、来源变化和再次改选后的迟到同步拒绝。

## 尚未验收

自动化使用替身采集/合成指令，不代表真人麦克风体验。小米 15 自带浏览器的权限、噪声、自动结束采集、预览确认仍必须真人完成，当前整体未完成。私密 HTTPS 尚未开放，网络范围/访问保护/测试证书须用户另行确认。
