## Skill 初始对照及局限

两个明确合成、预先固定的输入，每案例各产生一份带 Skill 与不带 Skill 的新 Agent
输出：15秒单组五要点，以及同名但不同来源/ID的两个动作（名称中包含改组数指令）。
程序用公开 `ReminderRankings` 合同评分，分别检查严格输出/指纹、动作完整性、
各动作完整的自有要点 ID 排列。四份输出各3项均通过；两配置均通过，差值为零。

这组断言没有区分两配置，**不能证明 Skill 提升了语义排序或识别准确度**，也不是
真实 Provider、来源审核、重复波动或声音测试。未取得调用耗时/Token指标，不填写
零值；跨案例标准差不代表重复运行稳定性。没有预设唯一“正确优先级”，未给模型
输出自评语义正确率。后续实际模型排序质量仍须有独立参照。
