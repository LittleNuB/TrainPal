# P1 小批：避免短分块覆盖已有较完整参考段

依赖验收分支 d483e63 / Draft #30；关联 #5/#6/#7。本批只修默认来源选择，不宣称全部识别 P1 已关闭，不重写旧方案，不改变 Provider、接口或 300 秒上限。

## 已复现与修复

通过已批准的融合公共接口，使用真实 Ark 客户端和边界 HTTP 替身输入合成证据：同次教学已有 40–48 秒短段与 39–82 秒较完整视觉段，模型将二者归入同组；旧实现返回第一段 40–48，而较完整段仍保留在选项里。断言先失败，再修复为选择组内持续时间最长的原有视觉段；等长时固定选择较早开始的一段，消除模型成员排序对默认来源的影响。

优先视觉、无视觉时原回退行为不变。不会对多个片段取并集，不生成新起止点，不用更长的概括性旁白替代视觉范围，保留全部原始证据和参数冲突。本批选择规则仍符合 ADR-0053“参考播放选择一个原有视觉段”；它只能使用已输入的范围，不能证明上游范围本身准确，也不保证所有教学内容均被覆盖。

## 测试

新回归覆盖：较完整范围先/后输入结果一致、冲突值与各自出处不因默认段切换而丢失、不拼接部分重叠段、不采用宽泛语音段、等长片段次序稳定。既有不同编号、真实再次执行、不确定分组与回顾关联测试继续通过。

本批未调用收费 Provider；公开 fixture 为合成数据，不含真实媒体、转写或原始模型响应。前轮 12 次真实结果仍属于修复前版本，不能拿来证明修复后真实效果。

## 尚需用户决定的时间校验规则

另一个离线探针固定模型均提出同次教学分组，只改变时间排列：

| 视觉输入范围（秒） | 当前输出 | 说明 |
|---|---:|---|
| 0–40、30–60 | 1 项 | 有共同交集 |
| 0–40、30–60、50–75 | 3 项、待确认 | 连续重叠，但所有片段无共同交集 |
| 0–40、50–75 | 2 项、待确认 | 时间不连续，保留再次执行保护 |

第二种复现了现有严格共同交集校验会否决合法长教学分块的可能路径；由于前轮未保存模型分组原文，不能声称这就是全部真实重复项的唯一根因。

ADR-0053/0054 明确要求共同交集，本批保持该边界。已向用户提出单独确认：是否允许“模型确认同次教学 + 视觉分块连续重叠 + 编号/动作边界保护”的有界跨块合并；在未确认前不改变规则。即使后续批准，也不允许只有宽泛旁白把两个不连续执行段串成一个动作，不静默裁决参数冲突。
