## 已实现的部分

- 动作编辑的来源要点支持逐条核对，默认不选；动作名称确认不隐含提醒审核。
  待确认动作不能审核为主动提醒。出处和原有文字要点仍可查看。
- 方案概览增加一个“训练时听动作要点”开关，缺少旧偏好时默认关闭。
  开启并有合法审核内容才准备安排；失败明确显示文字可用，不自动重试。
- 安排沿用已实现 HTTP、版本指纹和缓存合同。编辑、离页、关闭或开始时取消未完成
  请求；迟到结果不写入现行方案或已经开始的场次。审核、偏好及训练量变更使旧安排失效。
- 新场次先验证完整草稿的安排，再排除待确认动作，使用独立冻结快照。关闭偏好不
  冻结旧开启安排；实际执行不得读取未纳入场次的动作。
- 偏好写入串行使用最新值，避免小猫设置等并发写入恢复旧播报偏好；挂起状态属于
  store，组件卸载不再留下永久开练锁。
- 关闭保存失败时当前应用保持关闭，提示重试；磁盘可能仍是旧设置，完整浏览器
  重载后不能保证关闭已经持久化。没有用内存状态冒充保存成功。
- 仅可选提醒缓存未保存时，可省略缓存并保存实际方案，以文字训练继续；真实方案
  仍保存失败时必须阻止开始，不能绕过用户数据保护。

沿用已确认的暖白/鼠尾草视觉，不全面重做页面；审核保持折叠的逐条选择，概览只
增加一个开关，避免额外信息密度。本报告不表示声音已播放。
