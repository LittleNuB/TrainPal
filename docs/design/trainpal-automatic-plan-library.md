# 方案库自动归档切片

用户确认：每份进入方案编辑的训练方案自动保留，不额外要求“另存为”；复制方案才产生独立副本。相关取舍与原有合同替代关系见 ADR 0049。

验收边界沿用已确认的方案页面，通过隔离浏览器的真实本机数据库验证。核心场景：

1. 第一次使用方案即存档；修改与刷新仍只有一个同身份方案。
2. 复制产生独立副本，不覆盖原方案；删除当前副本后刷新不会复活。
3. 新建/切换方案先保存旧方案；两份都能从方案库找回。
4. 接受新分析结果自动存档，尚未接受和失败分析不归档。
5. 旧未存档草稿安全补存一次；已存方案不重复创建。保存失败保留编辑内容并允许重试。
6. 仅本机持久化；不涉及云端资源、Provider 调用、推送或部署。独立动作库暂不实现。

UI：训练页明确呈现“方案库”、新建和打开入口；编辑页显示方案库保存状态，“另存为/保存副本”改为“复制方案/创建副本”。退出不会删除方案，删除需明确确认并说明当前编辑器会关闭、训练记录仍保留。
