# TrainPal 对着视频练 v1

原始决策日期：2026-09-18；2026-09-19 按分批发布计划迁移。个人仓库 LittleNuB/TrainPal。规格 #21，分批 #22 / #23 / #24。本轮结果只记在对应 migration 文档；旧集成测试不作为本轮已通过证据。

## Problem Statement

参考视频只播放一次、每组都要点击继续，打断跟练。来源要点尚未贯通分析、方案与训练；同动作的参数冲突会拆成重复候选。用户也不能用自然语言调整当前观看内容。

## Solution

先把对着视频练做好：当前教学片段循环、同动作组间自动衔接、换动作先准备，TrainPal 展示来自视频的简短要点。用户可主动用文字或单次语音请求调整片段；训练暂停，先看建议，再明确继续。播放与确定性训练进度保持独立。

## User Stories

1. 首次训练能看到完整教学范围，先摆好器械再开始。
2. 当前选段在本组执行时循环，不自动把片长当作训练时长或次数。
3. 次数组只需一个大按钮确认完成；时长组到时自动完成。
4. 同动作休息到时，3 秒准备倒数后自动开始下一组。
5. 换动作时先显示教学与准备信息，点击“准备好了”才倒数。
6. 视频默认保留原声，倒数提示期间降低原声音量，随后恢复，也能静音。
7. 小猫一次只呈现一条视频要点，展开后能查看其余要点与出处。
8. 分析、接受方案、编辑、归档、刷新和复练都保留这些要点。
9. 同次示范参数有冲突时只看到一个待确认动作，并能看见冲突值和出处。
10. 文字或一次语音可以请求跳过准备、重看呼吸说明或循环演示。
11. AI 查找期间训练暂停、保留进度；先预览，再明确接受并继续。
12. 失败、取消或迟到回答不改变原选段，也不自动恢复训练。
13. 确认后的片段随方案保存，下次复练沿用；可以恢复完整教学。
14. 临时回退 5 秒只影响当前播放位置，不改方案。
15. 离开页面、切后台、刷新或存储失败时不在后台继续累计动作。

## Implementation Decisions

- 默认准备倒数 3 秒；恢复未完成组直接继续原进度。新组倒数不算训练时间。
- 前台同动作组间自动倒数；切后台期间休息可以自然流逝，但返回后必须明确继续，不能补跑动作。
- 完整教学范围与用户观看选段分开保存，原始来源证据只读。旧方案无额外选段时使用现有来源范围，不伪造扩大范围。
- 模型只能返回当前动作已有证据范围的标识；代码核验范围、来源、输入版本与动作绑定。信息不足时明确不能找到，而非生成时间点。
- 播放调整不改训练参数；AI 无训练状态机权限。单次有界调用，取消与超时后保持暂停。
- 单次语音采集只在用户点击后开始，自动结束；兼容性不足、拒绝权限或失败时保留文字入口，不承诺所有浏览器支持。
- 视频要点最多三条，限准备、路径、呼吸、节奏、注意事项，来自明确语音或字幕并带引用。不启用新的网页/通用知识补充链路。
- 同次示范身份与字段冲突解耦；冲突值不静默覆盖、平均或投票。不同编号、不同变式和真实再次执行仍保护。
- 沿用当前 Provider、本机存储、300 秒分析上限、原媒体清理规则。服务端不留原始转写、指令、录音或模型响应。

## Testing Decisions

最高层验收接口为“分析结果进入方案”和“完整训练旅程”，覆盖 HTTP、store、确定性训练执行器。按单批 RED → GREEN；最终完整 pnpm check / E2E、手机与桌面实屏、Standards / Spec 独立审查。合成测试、真实 Provider 抽测和人工真机体验分别报告，不以技术通过冒充准确率。

## 分批验收

### #22 低操作完整训练旅程

- [ ] 准备 → 倒数 → 执行 → 休息 → 同动作自动倒数；换动作准备。
- [ ] 片段循环与进度独立；原声、静音、倒数压低和恢复（真实手机听感待人工体验）。
- [ ] 背景、刷新、延迟计时、存储冲突不自动训练。
- [ ] 桌面 / 手机各完成次数与计时动作（Chromium 响应式实屏）。

### #23 来源内容进入训练

- [ ] 视频要点证据绑定、无依据不补造；保存、刷新、复练可用（语音校验精确引用；字幕仍依赖模型判断，非人工逐帧保证）。
- [ ] 一次一条与展开出处；不与主训练操作竞争。
- [ ] 同动作字段冲突单项呈现且保留双方出处；不同编号/真实重复保护。
- [ ] API → 方案 → 训练回归与有限真实样本核验；未宣称准确率。

### #24 片段调整闭环（依赖 #22、#23）

- [ ] 文字与单次语音入口、可见采集状态、自动结束、文字降级（自动化采集测试 + 真实 ASR 合成指令，未代替真人麦克风试用）。
- [ ] 暂停 → 查找 → 预览 → 接受并继续；失败/取消保持原片段和暂停。
- [ ] 合法范围与时效校验；参数不可改，迟到不可覆盖。
- [ ] 随方案持久化、复练、恢复完整教学；临时回退不保存。

D 的当前验证见 trainpal-watch-migration-20260919.md；E 与真机尚待验收。上列为目标检查单，不表示已经通过。

## Out of Scope

听提示专用模式、开放式 AI 私教、常开麦克风、姿态识别、长视频扩容、正式 Provider 切换、全面视觉重做、云端部署、Ready/合并或推送整条集成分支。

## Further Notes

本次批准取代 ADR-0017 的单次参考播放，以及旧的同动作组间手动继续；后台不训练、新动作准备和确定性执行边界不变。相关质量母项 #7 与前端母项 #8 不因本批完成而自动关闭。现有旧标注工作树保持不动。
