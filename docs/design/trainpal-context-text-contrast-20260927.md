# 统一上下文：六次文本对照

用户于 2026-09-27 明确授权最多 6 次收费文本调用。无视频/音频上传、无 ASR、无自动重试。技术或格式错误立即停止；普通质量失败继续记录对照。关联 #37 / Draft #36。

## 冻结设计

复用现有 Ark 文本模型配置，不切换正式 Provider。两组使用同一输出 schema、同一判断提示及同一个证据上下文输入格式。`legacy_visible` 只保留旧链路可见的信息：没有原始转写，视觉描述最多 600 字；`complete_context` 保留完整转写与视觉描述。

因此这是“相同实验格式下的信息完整度对照”，**不是旧产品与新产品端到端对照**。两组共同采用实验格式说明；不能把实验结果直接推断为线上准确率变化。

每条案例的动作、提醒、时间和正确答案在调用前固定，答案不进入请求。

| 案例 | 预期 | 信息差别 |
| --- | --- | --- |
| ambiguous_transition | 不选转场“坚持完成4组”；保留明确的胸部贴垫提醒 | 两组输入完全相同，作为重复对照，不应将输出差异归因于上下文 |
| visual_tail_scope | 不把上一动作4组收尾挂入反向飞鸟；保留两个动作各自正确提醒 | 明确归属说明位于600字后；人工构造填充文本，仅检查截断边界，不宣称真实视频曾出现这种输入 |
| spoken_negation | 不选“耸肩”，保留“胸部贴住靠垫” | 完整原句为“做反向飞鸟时，胸部贴住靠垫，不要耸肩。”；旧可见信息缺少该原句 |

六格顺序固定为：模糊旧→模糊完整→视觉完整→视觉旧→语音旧→语音完整。每格一次，无多次采样或随机化统计检验；模型服务版本、采样随机性和时间因素未控制，不宣称稳定或唯一因果。

## 执行与判分

工具 `services/analysis-api/scripts/context_attribution_contrast.py` 使用已审查的公共上下文适配、真实 Ark 响应解析和候选融合。复用上一轮的原始格式审计及评分函数，仅将这些实验辅助函数改为可复用名称。应用不导入这些脚本。

模型原文在内存中先检查明确字段及要点列表格式，再按动作成员/角色/关联、要点选择、原参数/范围和最终提醒归属与原文计分；格式错误不因生产容错而算通过。正确答案是构造的开发答案，不是被测模型自评。

启动器先以 HTTP 替身跑六格，冻结代码提交、案例和实际请求指纹。正式发送前逐格核对指纹、固定官方 endpoint、相同模型、store=false 和单次请求预算。独占 started/sent/result/stop/complete 文件防止重复运行；这些忽略目录中的记录只含状态、计数、耗时与指纹，不保存原始请求/模型回复或凭据。异常仅记受控状态。

本次完成六格或首次技术失败后，预算不得自动复用。即使六格都通过，也只支持后续验证，不直接接入产品，不宣布真实视频或17个语义案例全部通过。

## 准备测试

新增27项离线测试，覆盖六格冻结答案、错误提醒、全删漏失、非法格式、提示与输出合同一致、可见证据差异、重复对照相同输入、超时和取消。与原42项对照及21项上下文测试合计90项通过。执行结果另行补记。
