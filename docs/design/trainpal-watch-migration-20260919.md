依赖 C 批 b2ed37c / #27；关联 #22、#23。旧集成实现只作迁移来源，未替换 A 的方案调整和存档仓库。

## 行为与兼容

- 新建场次标记 watch-v1；旧未完成场次保持旧流程。
- 首次和新动作点击准备好了，三秒倒数后执行。同动作休息结束自动倒数。
- 次数手动完成，时长由训练时钟完成；循环参考视频不完成训练组。
- 暂停保留未完成组进度、剩余休息。页面隐藏/刷新/计时器长时间挂起不补跑训练。
- 原声默认开，可静音；可选倒数音无法启动不阻止训练。
- 视频要点一次一条，展开出处；没有可靠要点不补造。
- 已存选段与原始来源范围分离。包含选段持久化的内部合同和事务测试，为 E 的交互入口提供基础；本批不启用文字/语音请求。

后续独立 Standards / Spec 审查以 C 的 b2ed37c 为固定比较点。旧集成验收文档没有作为当前质量报告提交。

初审发现并复现两个 P1：准备命令慢保存时离页暂停被跳过、休息 tick 严重迟到仍自动开练；以及一个 P2：休息阶段没有暂停入口。已增加结算后读取状态的离页屏障、休息迟到保护和暂停按钮。新增测试先失败，修复后专项通过，覆盖隐藏、pagehide、路由离开三种情况。完整检查与旅程继续复跑。
