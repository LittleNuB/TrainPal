# 统一证据上下文：第一批离线验证

日期：2026-09-27。关联 #37 / #23，依赖 Draft #36。起点 `8612bb9`。

## 回答的问题

已有语音原句、视觉描述及相邻内容，能否完整抵达现有的候选融合模型输入？本批只回答信息传递问题，不评判模型是否把提醒归给了正确动作。

正式链路仍按 ADR-0053/0057 工作。实验位于 `services/analysis-api/scripts/evidence_context_probe.py`，应用不导入；没有修改 Provider、提示词文件、公开合同、存储、前端或演示服务。没有读取凭据或调用收费模型。

## 已实现的实验适配

- 在转写仍可用时接收一次运行的语音/视觉证据包。调用方显式提供并核对运行、来源及版本绑定；内容指纹参与引用 ID，输入变化后旧 ID 不再相同。绑定校验只能防止混用，不能证明调用方提供的内容确实来自原视频。
- 语音保留与动作范围相交的完整句子及紧邻前后句，不发送整份无关转写。支持短句必须与同时间原句逐字匹配；不存在的模型短句不被当成原文发送。子串匹配仅表示可追溯，不能判定否定、条件或动作归属。
- 视觉描述保留全文，包括超过原 600 字限制的尾部和非训练转场观察。描述仍标为未经独立核验的视觉模型输出，不改称 OCR、人工标注、字幕或章节依据。
- 所有记录共享本次分析时间坐标，不增加时间偏移；调用方须事先完成现有的分块/分析范围换算。非法时间拒绝。当前实验不验证编排层的偏移执行。
- 缺少视觉字幕、章节和切换覆盖依据时明确列出缺口。语音片段之间的时间间隔也显式标注；没有间隔仍不宣称连续性已确认。
- 增强后的输入仍受 64,000 字节限制。超限不裁掉句尾或冲突，而是停止该次融合请求，保留原动作、清空未审核提醒并返回实验状态。沿用原 200 条动作上限。
- 只在内存中工作，结束时释放实验适配器持有的上下文；调用方继续负责其输入对象的生命周期。没有文件、数据库或日志内容写入。

## 没有完成、不能宣称的事

规格 P01/P02/N01–N15 是后续语义验收目标。本批只覆盖它们涉及的信息传递和输入失效问题，**没有声称这 17 个语义案例通过**。尤其“耸肩”匹配“不要耸肩”仍可被现有模型错选；实验只保留完整原句并提示不得把子串匹配视为批准。

尚未扩展模型输出为正向归属引用，也未实现输出引用的逐条合法性审核。因此不能声称已拒绝所有未知、跨动作或错误语义引用。现有要点 ID 保护保持原样。

当前模型测试替身的回复是预设答案；本批不提供准确率、提升幅度或耗时结论。之前六次视觉构造对照没有获得可靠改善，该事实不因本轮信息传递通过而改变。
