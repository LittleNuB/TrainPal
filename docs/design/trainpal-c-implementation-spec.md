# TrainPal C：完整页面实施口径

日期：2026-09-08。视觉方向已获用户确认；实现需经过实屏和行为验收。
固定代码基线：`c6db764`，仓库 `LittleNuB/TrainPal`，隔离分支 `agent/complete-optimization-20260824`。

## 用户已确认的需求

- 首页主任务是选择健身视频，不能让快速方案替代视频入口。取消“本地视频优先／动作可校正／同设备继续训练”标签排。
- 使用用户选定的 C 温暖陪伴参考：暖白背景、灰绿承托面、墨绿正文、陶土色主按钮，简单圆角、自然中文、适度留白。去掉工程口吻、纸张网格、装饰英文和贴纸。
- 手机重排信息结构，首页／训练／我的三项导航保持；分析、方案、问卷、训练、结果为沉浸流程。
- 桌面单独优化，允许 SaaS 式窄左栏；宽屏分析采用视频与结果双栏，方案采用完整动作列表，训练采用视频与操作双栏，我的与训练结果采用宽屏分区。
- 覆盖首页、视频分析、训练库、方案／动作编辑／两步调整、训练及休息、结果、我的／档案面板、GYMTI 答题／结果／七猫选择。
- 保留方案页可拖动猫咪、方向键移动、位置记忆、收起恢复、关键操作避让。未确认风格时不强行选猫；不新增另一套猫咪资产。
- 恢复真实视频分析，不把 mock、缓存或快速体验方案当作 AI 结果。四个授权视频需要真实验证；待确认动作仍须确认，覆盖缺口与 Provider 错误仍需诚实呈现。

## 不变的功能约束

分析必须由用户显式启动，可取消、同设备恢复，覆盖完整所选来源或显式缺口范围。保留五条 manifest 受控来源及分析前确认；折叠不会创建请求。全部操作沿用公开 HTTP、store 与既有训练状态机。

方案保留命名、手动创建／编辑／排序／删除、复制、来源预览、另存为、开始／继续训练。字段仍为组数、次数或时长、休息、重量及既有来源标记。

AdjustmentPolicy.v1 不扩展：先选明确方向，再预览变化，确认后应用；保留视频明确参数、手动修改与重量；不适时停止建议。用户提出的“所有个性化数据生成专属计划”仍待单独设计，不在本轮视觉更新中偷换成已完成能力。

GYMTI 原问题、跳转、稳定 ID、正式结果和七猫资产不变。模型增强仍服从独立隐私门；当前本机未确认 retention 时使用确定性问卷结果，不打开该门。

原视频仅可保存在用户浏览器本机；服务端临时副本、音频、视频窗口和 Provider 内容在终态清理。凭据留在忽略的 `.env.local`，不得出现在前端、日志、截图、提交中。真实验证只留状态、计数、耗时和脱敏代码，不能把“覆盖完整”写成“动作识别准确率已验证”。

## 验收

1. 320／390／768／1440 无横向溢出；交互目标至少 44px；低动效、焦点约束及 WCAG 自动检查。
2. `pnpm check` 和完整 E2E，失败优先补回归再修复；合成流程与真实 Provider 证据分开报告。
3. 四个授权视频从选择、显式分析进入可编辑方案；至少一个真实结果继续验证参数编辑、训练、实际记录。
4. 双轴代码审查，Standards 与 Spec 独立报告；没有未解决 P0/P1 才称本地版本可交付。
5. 本地验证不等于生产上线、真机触控体验或训练处方有效性验证。不得推送、开 PR、合并、部署或操作云资源。

## 本机运行

在隔离 checkout 根目录保留已有且被 Git 忽略的 `.env.local`。默认可运行 `pnpm dev`（前端 5173，API 8000）。

要使用本轮预览端口 15174：API 终端先设置 `$env:CORS_ORIGINS='http://127.0.0.1:15174,http://127.0.0.1:5173'`，再运行 `pnpm dev:api`；另一个终端运行 `pnpm --filter @hachimi/web dev --host 127.0.0.1 --port 15174`。前端默认代理到本机 8000；如进程中留有旧 `VITE_API_TARGET`，设为 `http://127.0.0.1:8000`。

本机启动配置详见 ADR 0047。没有凭据时应明确报未配置，不降级到假分析。示例目录是否存在独立于本地视频上传；不为恢复示例而上传其他私有媒体。
