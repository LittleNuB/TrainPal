## 可验收行为

1. 用户接受分析结果、添加手动动作、选择快速体验后，非空方案自动存入方案库；编辑、重命名更新同一份。
2. “复制方案”创建独立身份；复制期间暂时锁住编辑，避免晚到的存储结果覆盖新修改。
3. 新建、切换、再练历史记录前保存当前修改；保存失败时不替换。
4. 未接受分析、空结果、分析失败、未关联的空编辑器不创建存档。
5. 旧非空草稿首次加载自动补存；移除旧字段而保留用户值；可识别的旧快速体验仍标注示例来源。
6. 删除当前方案清空编辑器，不删除训练记录；旧标签页不能把已删除方案自动复活。
7. 调整后的方案保留基础值，切换再打开仍可恢复；复制保留已应用调整，但丢弃绑定旧身份的未应用建议。
8. 存储仅限当前浏览器；清除浏览器数据会丢失，不宣称云端备份、版本历史或跨设备同步。
