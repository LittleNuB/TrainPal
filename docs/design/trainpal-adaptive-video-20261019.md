# 横竖屏视频与训练播放体验

2026-10-19，用户指出首页竖屏视频太小，并要求优化横屏、竖屏及训练中的播放体验。关联 #8、#21。延续 ADR-0085 的浅色界面与深色视频区域。

## 呈现

- 首页选片、分析来源、方案来源预览和训练示范共用播放器。读取媒体实际宽高；横屏按原比例利用宽度，竖屏依据视口高度显示完整画面，不裁切人物或字幕。
- 文件信息位于播放器下方。播放、声音、片段进度和放大按钮位于画面外，触控按钮至少 44px。
- 放大观看使用可收起的全视口窗口。保留同一个 video 元素、当前位置和来源；支持 Escape、焦点恢复和背景不可交互。
- 训练页在画面外展示当前组数与次数/时长。播放进度以当前合法动作片段为边界，提供重看本段；这些操作不修改来源或训练量。
- 2026-10-20 用户明确修订：放大与收起仅改变观看方式，训练与倒计时保持运行。在放大画面内保留动作、组数、实时次数/剩余时长及完成本组、暂停、继续/提前继续等当前状态对应的操作。使用同一训练控制组件与原有命令；失败和冲突提示在放大画面内可处理。单独暂停示范不会暂停训练，也不能被计时刷新强制恢复。
- 同日追加：放大模式保留“跟我说”和“语音唤醒 · 开/关”，同一个助手随播放器移动，已有唤醒授权、监听与请求状态保留，也可在放大模式主动开启。喊 TrainPal 后使用原有暂停/继续、回退、AI 查找片段、预览、确认/取消流程，无需收起视频；发起请求时暂停训练，明确确认或继续指令后恢复。关闭助手面板只返回放大视频，Escape 分层关闭并恢复对应入口焦点。横放短屏将助手与训练按钮并排，保留画面空间；隐藏页面或离开训练仍关闭监听。沿用 ADR-0088 的训练量编辑边界。
- 同日支持“TrainPal，完成本组”：对正在进行的次数型动作，明确口令直接走原有完成流程，记录当前组并进入休息、换动作或结束。普通与放大模式均支持整句口令和先唤醒再说指令，成功后收起助手面板并继续保持唤醒开启。指令绑定会话版本、动作、组次及唤醒前状态，重复回调或倒数跨阶段不会多记一组；计时动作仍由计时器完成。
- 删除首页常驻的时长/大小/核对说明与隐私折叠块，视频隐私说明移至“我的 → 设置与本机数据”。文件不满足限制时再显示具体处理提示，不改变实际校验上限。
- 无视频、读取失败与自建动作仍可训练；播放结束仍不等于完成本组。未点击分析不发起模型任务。
