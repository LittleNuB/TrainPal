# TrainPal 移动体验设计 Brief

Status: frozen and implemented for Vue design v1 / GYMTI v1 release candidate

Updated: 2026-07-23

Applies to: 独立 Web、本地视频导入、分析、方案、个性化、训练、结果与个人中心

## 1. 体验命题

TrainPal 帮助已经找到并保存健身视频的用户，把视频转成一场可编辑、可立即执行的训练，并由同一个小猫教练在规划、训练和结果阶段持续陪伴。产品不模拟抖音信息流，也不把所有能力堆叠在视频播放页。

设计必须让用户始终回答三个问题：我现在在哪一步、TrainPal 正在做什么、下一步唯一需要做什么。

## 2. 视觉方向

整体方向为“温暖训练手账 × 小猫教练”：

- 首页、方案、个性化、训练中心、个人中心和结果使用温暖明亮底色、深色正文、大号训练数字与明显留白。
- 训练中页面切换为高对比深色舞台，优先保证来源视频、计时、组次和主操作清晰。
- 小猫教练通过教练卡、贴纸式状态、阶段反馈和休息召回出现，不复刻抖音右侧悬浮操作栏。
- 整体保持利落、运动和有陪伴感，不使用儿童化糖果组件、通用 AI 紫色渐变或贯穿全站的霓虹黑底。
- Vue v1 锁定下列语义设计 Token；猫咪品种色在正式资产交付后只能作为角色层扩展，不改变页面主题和主操作颜色。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--tp-canvas` | `#F3EFE5` | 手账页面背景 |
| `--tp-surface` | `#FFFDF8` | 明亮卡片与表单表面 |
| `--tp-ink` | `#1C2822` | 主要文字 |
| `--tp-muted` | `#6C746E` | 次要文字 |
| `--tp-primary` | `#D94B2B` | 唯一主操作与关键进度 |
| `--tp-secondary` | `#A5BA63` | 非阻塞陪伴与完成反馈 |
| `--tp-line` | `#D8D5CA` | 分隔与边界 |
| `--tp-training-canvas` | `#0E1311` | 训练舞台背景 |
| `--tp-training-surface` | `#18201C` | 训练控制表面 |
| `--tp-training-ink` | `#F7F3E9` | 训练舞台文字 |
| `--tp-focus` | `#2459D6` | 键盘焦点 |

训练数字与短英文继续使用已经进入工程的 Barlow Condensed；中文正文和控件使用高可读系统中文字体栈。Vue v1 不新增大型中文 Webfont。

## 3. 页面架构

### 首页 / 导入

- 一个核心价值陈述。
- 一个“选择健身视频”主入口。
- 选片后出现轻量预览：缩略图、文件名、时长、处理与隐私说明。
- 唯一主操作变为“开始分析”。
- 最近项目只显示少量可恢复项目，不形成内容 Feed。
- 五条已授权受控视频以相同中性标题和时长按钮提供“快速真实分析”；点击后先说明会调用真实 AI、需要等待且结果需核对，再由用户确认开始。单并发容量不足时显示“当前有分析正在进行，请稍后重试”，不要求先输入评委码；前一条终态清理后可立即再次开始。

### 分析

- 来源视频静态或低干扰预览。
- 真实阶段、覆盖进度和已发现动作数。
- 取消或错误后的重试。
- 用户可以离开；其他页面以轻量入口提示任务状态。
- 完成后主操作为“查看训练方案”，不自动跳转，不在本页编辑动作。

### 方案

- 顶部只显示方案名称、动作数、约用时和必要的覆盖提醒。
- TrainPal 教练卡提供可选的“让 TrainPal 调整这次训练”。
- 点击后使用 Bottom Sheet 先选择“更容易完成／更有挑战／控制用时”，再展示完整差异并由用户整体确认；GYMTI 与教练风格保留为独立次级入口。
- 动作使用摘要列表，只展示名称、组数、次数或时长和休息。
- 点击动作后用 Bottom Sheet 编辑完整字段、查看来源片段、证据和动作要点。
- 底部固定“开始训练”为唯一主操作；排序、复制、删除和新增是次级操作。

### 首次个性化步骤流

- 只在用户主动选择个性化时进入。
- GYMTI、训练经验、小猫教练风格和可选个人信息按步骤分屏，不塞入方案页。
- 支持返回与稍后完成，不阻塞用户使用基础方案。
- 问卷、完善训练档案、结果和风格改选统一使用现有 TrainPal 手账主题与沉浸式页面外壳，不显示底部导航，也不使用独立遮罩抽屉或第二套设计 Token。
- 问卷原型只保留内容与经确认的插画素材；候选轮播、“换一只哈基米”和重复猫头像不进入正式流程，推荐与改选统一解析共享七猫目录。
- 自适应题目页头显示返回、`GYMTI` 和 `第 n 题`，题目区说明“通常 5–8 题”，第 8 题显示“最后一题”；不使用会在提前结束时产生误导的百分比或固定八段进度。
- 第 2 题以后返回上一题并恢复原选择，改答会截断后续路径并重新选题；第 1 题返回来源页但保留尝试，题目页不再增加第二个关闭入口。
- 点击选项即提交并自动进入下一题，短暂显示选中态并阻止重复点击；题目页不设置“继续”或“完成答题”按钮，需要改答时使用页头返回。
- 选题等待保留当前题目和选中态，以中性内联文案提示；正常模型降级不打断用户，只有无法产生合法题目时显示保留尝试的重试／退出故障页。
- Ark／豆包模型增强的三并发门与视频分析容量独立；第四条并发或模型错误直接走本地降级，界面不暴露供应商错误、不增加排队页，也不改变答题操作。
- “完善训练档案”用一页四项表单，390px 两列、320px 单列；清楚说明可跳过且不影响测评，底部固定“保存并查看结果／跳过”，已有档案才显示清除入口。
- 结果页先展示 GYMTI 插画、主要类型、核心解释、正向原因与低强调次要倾向，再展示推荐小猫卡；底部只有“确认这个风格”一个主操作，“修改风格”在卡内，“重新测评”放在页面末尾。
- 风格改选页一次展示七张卡：320px 单列、390px 两列、桌面最多三列；仅临时选中卡播放待机动画，点击只暂存，底部明确确认才保存，返回结果页丢弃临时选择。
- GYMTI 人物插画裁去内嵌标题与小字，只在结果页静态展示；答题与档案页不放人格插画或猫，结果页仅推荐猫待机，低动效模式使用静态首帧并取消题目切换动画。
- 320／390 保持单列结果层级，宽屏继续使用最大 760px 内容容器；视觉回归覆盖 320、390 与 768px。

### 训练中

- 视频位于上半区并按原始比例 `contain` 展示，不固定为 9:16。
- 中部只显示当前动作、当前组、目标次数或时长，以及最多一条当前要点。
- 底部只有一个随状态变化的主按钮。
- 暂停、跳过、临时调整和提前结束进入“更多”或 Bottom Sheet。
- 小猫教练位于控制区旁；点击后展开完整要点，不覆盖视频。
- 休息阶段放大小猫和倒计时，结束后进入“准备继续”，绝不自动开始。

### 训练结果

- 首屏突出完成内容、训练时间、约消耗卡路里和陪伴成长反馈。
- 海报和分享是次级操作，不把全部动作明细塞进首屏。
- 提前结束与完整结束使用不同但不羞辱用户的结果表达。

### 训练

- 优先显示“继续未完成训练”或当前方案，两者不会同时形成两个主按钮。
- 其次展示少量已保存方案，并提供进入完整列表的入口。
- 不重复展示训练记录、档案和设置。

### 我的

- 承载训练记录、GYMTI、个人信息、小猫教练风格、陪伴成长和设置。
- 各模块使用独立详情页或 Bottom Sheet，不在首页一次展开全部字段。

## 4. 导航

- 顶层底部导航只有 `首页 / 训练 / 我的`。
- 首页、训练和我的显示底部导航。
- 分析、方案编辑、个性化步骤流、训练中和结果使用顶部返回，不显示底部导航。
- 存在未完成训练时，非训练页面显示统一且不遮挡当前主操作的“继续训练”入口。

## 5. 移动端与响应式

- 主要设计视口为 390×844，同时完整支持 320px 宽度。
- 所有关键触控区域至少 44×44 CSS px。
- 使用 `100dvh` 和 `env(safe-area-inset-*)` 处理浏览器栏与刘海区。
- 表单和 Bottom Sheet 必须适配软键盘，不让固定按钮遮挡当前字段。
- 移动端所有主流程均为单列，不依赖悬停、右键或精细拖拽。
- 更宽屏幕可以为方案和分析增加辅助预览，但页面仍只有一个主要任务和一个主要操作。
- 桌面端不使用固定宽度手机外壳；内容采用响应式最大宽度和真实浏览器布局。

## 6. 渐进披露

- 首屏只展示完成当前任务所需的信息。
- 来源证据、完整动作字段、全部要点、危险操作和历史明细按需展开。
- 覆盖警告与安全提示不能隐藏在 Bottom Sheet；它们必须在相关操作前可见。
- 个性化理由使用整套差异对照，不在每个动作卡片重复长文案。

## 7. TrainPal 呈现

- 规划阶段：非阻塞教练卡和调整结果摘要。
- 训练阶段：小型状态角色和最多一条当前要点。
- 休息阶段：放大角色、倒计时和休息召回。
- 结果阶段：成长反馈和一个里程碑表达。
- 隐藏角色不会移除等价文字、训练控制或安全信息。

## 8. 动效与无障碍

- 动效用于页面阶段转换、小猫状态和任务完成反馈，不用于伪装模型进度。
- 支持 `prefers-reduced-motion`，低动效时保留完整状态语义。
- 正文、关键数字、按钮和视频控制满足可读对比度；状态不能只靠颜色表达。
- 键盘焦点、屏幕阅读顺序和错误关联在桌面与移动辅助技术下保持可用。

## 9. Vue 是视觉真源

- 不制作独立 Figma 文件；可运行 Vue 页面、开发设计画廊和自动截图共同构成视觉真源。
- `/__design/trainpal` 与七猫动画预览台 `/__design/trainpal/pets` 只在开发环境注册；前者用显式 Fixture 展示组件与失败状态，后者只验收既有动作，不连接生产 Provider、不选择或保存风格，也不成为运行时 Mock。
- 页面按用户旅程逐切片设计并立即接入真实 Store；每个切片在 320、390、768 和 1440 宽度下通过后再推进。
- 七猫动画使用独立 WebP 帧播放器接入既有安全框；未确认风格时正式页面不渲染任何小猫，文字、计时、要点和训练控制保持完整。
