# TrainPal 前端 v2：首批体验验收

状态：本地实现，待用户视觉验收。2026-09-07。

## 本轮已确认的方向

- 优先传达可靠、利落、可以立即开始训练的工具感。采用简洁的编辑式训练日志；保留纸张网格、墨绿、陶红和现有七猫资产，减少大胶囊、重复边框、英文装饰标签与贴纸。
- 桌面端单独布局，使用窄左侧栏：品牌、首页／训练／我的、当前任务、本机数据说明。用户明确接受 SaaS 式工具布局；不向侧栏塞入档案表单。
- 手机同时重构信息层级，保留三项固定底栏；分析、方案、个性化、训练与结果继续隐藏移动底栏。
- 首页上传是唯一主操作；五条受控来源后续收为紧凑次级入口，仍保留来源、授权、显式启动与真实分析合同。
- 方案保留动作卡片；只展示名称、待确认状态、组数、次数或时长及休息。完整编辑和来源在手机底部抽屉、桌面侧边面板中展开。
- 调整分为选择方向、核对完整变化两个阶段，确认后整体应用。模型随机重生成与综合档案个性化机制后续单独设计。
- 猫咪与动效保持低干扰。猫咪支持拖动、方向键移动、窗口内定位、避让关键操作、手机松手贴边、本机位置记忆，以及收起／恢复。

## 本次交付边界

先实现训练方案页、两步调整面板与方案页可拖动猫咪，提供 320、390、768、1440 四种宽度。共享导航作为桌面／移动外壳一并接入；首页、训练中心、我的、GYMTI、训练中与结果页的内容重排留待首批验收后推进。可拖动猫咪目前只接入方案页，其他页面仍使用原有猫咪呈现。

桌面断点为 1024px。方案左侧概览、右侧动作卡片，固定底部开始训练；动作详情／训练调整从右侧展开。手机使用单列，抽屉内可滚动并固定操作区。切换训练主题不保留上一页离场动画，避免旧页面出现在新主题下。

仅用户已确认风格后显示猫咪。布局位置是现有本机偏好的可选字段，无数据库版本迁移；手机与桌面分别保存相对位置。位置无效或窗口变小时重新约束；没有足够安全空间时收为恢复入口。拖动、隐藏与恢复不改变训练方案、计时、顺序或 GYMTI 结果；清除全部本机数据会一起清除位置。

## 验收项目

- 方案命名、手动增删改、排序、复制、来源查看、另存为、开始／继续训练仍可使用。
- 主列表不平铺来源和排序按钮；待确认动作仍明确标记且不自动进入训练。
- 选择调整方向后先看差异；返回修改方向不应用旧结果；应用／恢复保留原确定性字段与原子保存规则。
- 不适信号仍立即撤销未应用提案；无法调整时允许保留当前方案。
- 弹层内键盘焦点受约束，退出后恢复到触发入口；背景不滚动，猫咪在弹层打开时退场。
- 猫咪拖动、方向键、刷新恢复、收起／恢复、视口缩放后仍不遮挡关键按钮。
- 低动效、44px 触控区域、无横向溢出、WCAG 自动检查、完整 `pnpm check` 与 E2E。

## 后续个性化议题（未实施）

用户希望完整档案与所有相关数据进入个性化上下文，自动得到面向自己的训练计划，随后可手动修订或让 AI 继续调整。再次调整应有明确的新诉求或证据，不能只依靠模型随机性制造差异。数据清单、优先级、安全边界、生成／修改语义与重新调整机制，在前端盘点和首批验收之后继续讨论；本次不扩大 AdjustmentPolicy.v1 输入或能力承诺。
