## 两轴审查与修复

### Standards

独立审查最初发现 1 项 P2：保存训练经验时仍允许修改上下文，可能用旧经验生成建议。已在保存期间锁定经验、时间、精力、调整方向及健康输入，关闭弹层仍可取消后续生成。延迟保存测试检查禁用状态、保存后的真实经验及初学者只调整半数动作。

复审结论：未解决的规范违反 0，判断性代码异味 0。

### Spec

独立审查最初发现 2 项 P2：清除反馈后仍展示旧依据；动作折叠后丢失非法数字提示。

- 预览只显示原提案依据中仍与当前动作身份及反馈记录匹配的条目；依据数量、原因文案同步更新。输入阶段不展示旧提案依据，原提案保持不可变。
- 数字错误由当前字段值计算，折叠卡保留错误；应用前展开首个出错建议并聚焦字段。复查发现的“更改数字误清除重量等异字段错误”也已修复，只清除被修改字段的旧错误。

最终复审未发现未解决的 Spec 问题。两位审查者均进行只读审查；测试由实施方运行，结果列在上表。

最后的小屏修复也经两位审查者复核：输入焦点及可用视口变化触发避让，组件卸载清理监听和动画帧；未新增 Standards/Spec 问题。

## 本地复现

当前运行终端：Web `pnpm --filter @hachimi/web dev --host 127.0.0.1 --port 15180 --strictPort`，API `pnpm dev:api`。重启时在仓库根目录执行，保持原本的本地 Provider 配置。

建议体验顺序：快速开始 → 查看预设方案 → 展开一个动作修改数字 → 按我的情况调整 → 修改建议并应用 → 开始训练 → 完成后填动作反馈。原生设备与真实模型质量验收各按其既有证据范围继续跟踪。
