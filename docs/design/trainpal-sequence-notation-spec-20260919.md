# 编号格式兼容：小批规格

基线 #33 / `a294f0f`。关联 #6；范围见 ADR-0056。用户同意继续检查编号提取和统一格式，保护不同动作、左右侧和轮次。

## 本批验收

1. 沿用 ADR-0053 已确认的融合公共接口，先复现完整序号写法等价却产生两个候选的失败，再做最小修复。
2. `第N个动作` / `第N动作` 与原有同数字写法等价；仅匹配完整字符串，保留全部原始输入与来源。
3. 不同数字、侧别、轮次、变式、组数/次数和未知格式不因截取数字而相等；模型分组、不确定关系与时间保护不变。
4. 正式分组和参考关联共用身份规则。来源片段不拼接，视觉单源仍待确认；参数冲突保留双方数值与出处。
5. 不修改 Provider、提示词、日志、接口、前端或存储；不新增收费调用。既有真实样本原因仍区分“已定位编号护栏”与“未确定编号冲突的来源”。
6. 专项回归、完整检查、E2E、接口一致性与 Standards/Spec 双轴审查后，提交依赖 #33 的独立 Draft PR，不合并。

## 不在本批解决

视觉模型的跨块局部编号、错误读取编号，或语义模型误把不同动作分在一起，都需要更具体证据，不能靠格式归一掩盖。当前视觉提示词要求可见编号但没有严格跨块编号规则；本批只记风险，不在无真实对照时顺便修改模型行为。
